Reinforcement learning

The model-free face of the Markov decision process: with the transition kernel and reward unknown, the agent must learn optimal behaviour from sampled interaction alone — balancing exploration against exploitation.

1. The RL problem

A Markov decision process $(\mathcal S,\mathcal A,P,R,\gamma)$ becomes a reinforcement-learning problem the moment we erase $P$ and $R$. The agent no longer has the model; it only gets to act and observe. At each step it sees the state $s_t$, picks an action $a_t$, and the environment hands back a reward $r_{t+1}$ and a next state $s_{t+1}\sim P(\cdot\mid s_t,a_t)$ — one sampled transition $(s_t,a_t,r_{t+1},s_{t+1})$ at a time. Where dynamic programming on a known MDP computes $V^*$, reinforcement learning must estimate it from this stream of experience.

The objective is unchanged: maximise the expected discounted return

$\displaystyle G_t = \sum_{k\ge 0}\gamma^k\, r_{t+k+1},\qquad V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s].$

What is new is the exploration–exploitation tradeoff. To improve, the agent must exploit what it currently believes is best; but to discover better options it must sometimes explore actions whose value is still uncertain. The simplest reconciliation is the $\varepsilon$-greedy rule: with probability $1-\varepsilon$ take the action with the highest current estimate, and with probability $\varepsilon$ pick uniformly at random. Two orthogonal axes organise the algorithms ahead: model-free (learn values/policies directly, this whole page) versus model-based (first learn $\hat P,\hat R$, then plan); and on-policy (evaluate the very policy that generates the data) versus off-policy (learn about a target policy while behaving under another).

Worked mini-example. The widget runs an $\varepsilon$-greedy agent on a 5-state chain $s_0\!-\!s_1\!-\!s_2\!-\!s_3\!-\!s_4$. The action right advances toward the absorbing goal $s_4$ (reward $+1$ on arrival); left retreats. The agent does not know this — it only sees rewards as they arrive. Early on, a high $\varepsilon$ wanders; as $\varepsilon\to 0$ behaviour collapses onto whatever currently looks best, which is good only if exploration has already found the goal. 2. Monte Carlo prediction & control

The most direct way to estimate $V^\pi$ without a model is to take the definition literally. Run the policy to the end of an episode, record the realised return $G_t$ following each visited state, and average those returns:

$\displaystyle G_t = \sum_{k\ge 0}\gamma^k r_{t+k+1},\qquad \hat V^\pi(s) = \frac{1}{|\{t: s_t=s\}|}\sum_{t:\,s_t=s} G_t.$

Because $V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s]$ by definition, each observed return is a sample whose expectation is exactly the target, so the average is an unbiased estimator and converges to $V^\pi(s)$ by the law of large numbers as the number of visits grows. No transition kernel, no reward function — only complete trajectories. This is Monte Carlo prediction.

Two bookkeeping conventions: first-visit MC averages the return following only the first time $s$ appears in each episode; every-visit MC averages over all occurrences. Both are consistent. The price of MC is variance (a return is a sum of many random rewards) and the requirement that episodes terminate — you cannot update until the episode is over. Pairing prediction with $\varepsilon$-greedy improvement on the resulting estimates gives Monte Carlo control.

Worked mini-example. An episode visits $s$, then collects rewards $r_1=1,\ r_2=0,\ r_3=2$ before terminating, with $\gamma=0.5$. The sampled return is $G = 1 + 0.5\cdot 0 + 0.25\cdot 2 = 1.5$. Each new episode contributes another such sample; the running average is the MC estimate of $V^\pi(s)$. The widget draws returns from a state whose true value is $V^\pi=2$ and shows the running mean converging to it — with visible noise that shrinks like $1/\sqrt{n}$.

3. Temporal-difference learning

Monte Carlo waits for the episode to end. Temporal-difference (TD) learning does not: it updates after every single transition by bootstrapping — replacing the unknown tail of the return with the current estimate of the next state's value. The one-step TD(0) update is

$\displaystyle V(s)\;\leftarrow\; V(s) + \alpha\,\underbrace{\big[\,r + \gamma V(s') - V(s)\,\big]}_{\textstyle \delta},$

where $\alpha$ is the step size and the bracketed quantity is the TD error

$\displaystyle \delta \;=\; r + \gamma V(s') - V(s).$

The target $r+\gamma V(s')$ is exactly one term of the Bellman expectation equation, now sampled rather than averaged over $P$. At the true value function $V^\pi$ the Bellman equation $V^\pi(s)=\mathbb E[r+\gamma V^\pi(s')]$ forces $\mathbb E[\delta]=0$: on average there is nothing left to correct, so $V^\pi$ is the TD fixed point.

TD versus MC is a bias–variance tradeoff. MC's target, the full return, is unbiased but high-variance (a long sum of random rewards). TD's target bootstraps off a current estimate $V(s')$, so it is biased while that estimate is wrong, but it has far lower variance (it depends on one reward and one transition). TD also learns online and from incomplete, even non-terminating, streams. These are the two endpoints; $n$-step returns and TD($\lambda$) interpolate between them.

Worked mini-example. Suppose $V(s)=2$ and $V(s')=5$. The agent takes the transition $s\to s'$ and observes reward $r=1$, with $\gamma=0.9$ and $\alpha=0.1$. The TD error is $\delta = 1 + 0.9\cdot 5 - 2 = 3.5$, so $V(s)\leftarrow 2 + 0.1\cdot 3.5 = 2.35$. One transition nudges $V(s)$ a tenth of the way toward its bootstrapped target $r+\gamma V(s')=5.5$. 4. Q-learning & SARSA

TD(0) estimates $V^\pi$ for a fixed policy. To learn how to act we estimate action-values $Q(s,a)$, from which a greedy policy can be read off without a model. Q-learning applies the TD idea to the Bellman optimality backup:

$\displaystyle Q(s,a)\;\leftarrow\; Q(s,a) + \alpha\Big[\,r + \gamma\,\max_{a'} Q(s',a') - Q(s,a)\Big].$

The target uses $\max_{a'}Q(s',a')$ — the value of acting optimally from $s'$ — no matter which action the agent's behaviour policy actually takes next. That makes Q-learning off-policy: it learns $Q^*$ while behaving under any sufficiently exploratory policy (e.g. $\varepsilon$-greedy). Its on-policy sibling SARSA (state–action–reward–state–action) instead bootstraps off the action $a'$ actually taken:

$\displaystyle Q(s,a)\;\leftarrow\; Q(s,a) + \alpha\Big[\,r + \gamma\, Q(s',a') - Q(s,a)\Big].$

So SARSA evaluates and improves the very (exploratory) policy it follows, which makes it more conservative near risk; Q-learning targets the greedy optimum directly.

Why does Q-learning converge to $Q^*$? Each update is a stochastic-approximation step (Robbins–Monro) toward a sampled version of the Bellman-optimality operator $T$. That $T$ is the same $\gamma$-contraction that drives value iteration; provided every $(s,a)$ is visited infinitely often and the step sizes satisfy $\sum_t\alpha_t=\infty$, $\sum_t\alpha_t^2 < \infty$ (steps big enough to travel anywhere, small enough to average out noise), $Q$ converges to $Q^*$ with probability $1$ — sampled value iteration.

Worked mini-example. Take $Q(s,a)=4$. The agent does $a$, gets $r=2$, lands in $s'$ with $Q(s',a_1')=3,\ Q(s',a_2')=7$, and $\gamma=0.5,\ \alpha=0.1$. Q-learning bootstraps off $\max(3,7)=7$: target $=2+0.5\cdot 7=5.5$, so $Q(s,a)\leftarrow 4+0.1(5.5-4)=4.15$. SARSA, if the next action actually taken were the one with value $3$, would use target $=2+0.5\cdot 3=3.5$ and give $Q(s,a)\leftarrow 4+0.1(3.5-4)=3.95$. Same data, different bootstrap.

5. Function approximation

A lookup table needs one entry per state (or state–action) pair. That is hopeless when $\mathcal S$ is enormous (a chessboard, a screen of pixels) or continuous. The fix is to replace the table with a parametric value function $\hat V(s;w)$ or $\hat Q(s,a;w)$ — linear in features $\hat V(s;w)=w^\top\phi(s)$, or a neural network — and learn the weight vector $w$. Now experience at one state generalises to similar states through shared parameters, the same concern as empirical risk minimisation: we fit a function from finite samples and hope it transfers.

The natural update is semi-gradient TD. Treating the TD target $r+\gamma\hat V(s';w)$ as fixed, descend the squared TD error:

$\displaystyle w \;\leftarrow\; w + \alpha\,\big[\,r + \gamma\hat V(s';w) - \hat V(s;w)\,\big]\,\nabla_w \hat V(s;w).$

It is called semi-gradient because we do not differentiate through the bootstrapped target — that is what keeps it a fixed-point iteration rather than honest gradient descent, and it is also where trouble can start.

The deadly triad. Three ingredients, each harmless alone, can together make value learning diverge: (1) bootstrapping (TD-style targets that reuse the current estimate), (2) off-policy training (learning a target policy from data drawn under another), and (3) function approximation (a parametric, shared-parameter value function). The $\gamma$-contraction that guaranteed tabular convergence operates in the wrong norm once projection onto the function class enters; weights can blow up. Tabular Q-learning is safe because it lacks ingredient (3).

In practice, DQN tames the triad with two tricks: an experience-replay buffer (store transitions and sample minibatches, decorrelating the data and reusing it) and a slowly-updated target network (hold the bootstrap target's weights fixed for many steps so the moving target stops chasing itself).

Worked mini-example. Fit a linear value $\hat V(s;w)=w_1\phi_1(s)+w_0$ to a true value function that grows along the chain, using semi-gradient TD. 6. Policy gradients

Value-based methods learn $Q$ and act greedily. Policy-gradient methods skip the value function as the object of interest and optimise a parameterised policy $\pi_\theta(a\mid s)$ directly by gradient ascent on the expected return $J(\theta)=\mathbb E_{\pi_\theta}[G_0]$. This is natural for continuous action spaces and for stochastic optimal policies. The difficulty is that $\theta$ affects $J$ both through which actions are chosen and through the state distribution they induce — yet the policy-gradient theorem shows the messy state-distribution term drops out:

$\displaystyle \nabla_\theta J(\theta) \;=\; \mathbb E_{\pi_\theta}\!\big[\,\nabla_\theta \log \pi_\theta(a\mid s)\,\; Q^{\pi_\theta}(s,a)\,\big].$

The estimator is an expectation we can sample: follow the policy, and weight the score $\nabla_\theta\log\pi_\theta(a\mid s)$ by how good the action turned out. REINFORCE is the Monte Carlo instance — it replaces the unknown $Q^{\pi_\theta}(s,a)$ with the sampled return $G_t$:

$\displaystyle \nabla_\theta J(\theta) \approx \nabla_\theta\log\pi_\theta(a_t\mid s_t)\,G_t.$

This is unbiased but high-variance. The cure is a baseline $b(s)$: replace $G_t$ by $G_t-b(s)$. Because $\mathbb E_a[\nabla_\theta\log\pi_\theta(a\mid s)\,b(s)] = b(s)\,\nabla_\theta\sum_a\pi_\theta(a\mid s)=b(s)\,\nabla_\theta 1 = 0$, subtracting any state-dependent baseline leaves the gradient unbiased while shrinking its variance. The best baseline is roughly $V^{\pi_\theta}(s)$, so $G_t-V(s)$ measures how much better the action did than expected — the advantage. Learning that baseline as a value function gives actor–critic: the actor $\pi_\theta$ updates from the policy gradient, while a critic $\hat V$ (trained by TD) supplies the baseline and lets the actor bootstrap from incomplete episodes.

Worked mini-example. A two-action softmax policy at a single state, $\pi_\theta(\text{right})=\sigma(\theta)$, with the right action paying a higher expected reward. The REINFORCE estimator $\nabla_\theta\log\pi_\theta(a)\,(G-b)$ pushes $\theta$ up whenever a sampled right-action beats the baseline, so $\sigma(\theta)\to 1$ and $J(\theta)$ climbs. The widget plots $J(\theta)$ rising under gradient ascent; toggle the baseline to see the variance of the steps drop without changing where they head.

Connections

Reinforcement learning is the empirical face of the same Bellman backbone that dynamic programming attacks analytically: it trades a known model for sampled experience and inherits all the model-free difficulties that creates. The live frontier is exactly where the clean theory frays — the deadly triad and the (still incomplete) convergence theory for deep value learning, sample efficiency (real interaction is expensive), exploration in high dimensions far beyond $\varepsilon$-greedy, and partial observability, where the agent no longer sees the Markov state at all. Deep reinforcement learning married policy gradients and Q-learning to neural networks to play Go and control robots, but the stability guarantees of the tabular case largely did not survive the trip.

  • Markov decision processes — the MDP model — RL is exactly an MDP with $P$ and $R$ unknown; every value here is a sampled estimate of an MDP quantity.
  • Markov decision processes — value iteration — Q-learning is its sampled, model-free shadow, driven by the same $\gamma$-contraction.
  • Optimal control & dynamic programming — the Bellman equation — the continuous, model-based cousin; RL is dynamic programming when you cannot write down the dynamics.
  • Statistical learning theory — empirical risk minimisation — function approximation in RL is a learning problem: generalising a value function across states from finite data.
  • Optimal control — stochastic control — the same discounted objective under noise, the bridge between control-theoretic and learning-based viewpoints.

Two directions this page only gestures at, not yet in the notebook: partially observed MDPs (POMDPs), where a belief state restores the Markov property at the cost of an explosion in dimension; and deep reinforcement learning, where the value function or policy is a deep network and the analysis of when learning is stable is genuinely open.
