# klein-gordon-equation — pedagogical audit (2026-05)

**Section:** Mathematical physics
**Compared against:** schrodinger-equation, dirac-equation

## Summary
Solid, well-paced page with five interactive widgets that line up cleanly against the two siblings; voice and structure match category-theory.html and the dirac/schrodinger templates. A handful of small notation and helper-block hygiene issues, plus one minor jargon-before-definition slip and one widget readout that has gotten very long; otherwise no rework needed.

## Findings
### Notation drift
- Signature flip-flop, semantic: §1 introduces $\Box = \partial_t^2 - \nabla^2$ (mostly-plus claim), then §2 immediately gives $\Box \equiv \eta^{\mu\nu}\partial_\mu\partial_\nu = -\partial_t^2 + \nabla^2$ for the same "mostly-plus" $\eta = \mathrm{diag}(-1,+1,+1,+1)$, with a parenthetical that "Some authors absorb the sign and write $\Box = \partial_t^2 - \nabla^2$." The page is contradicting itself within two sections, not just nodding at a convention. Dirac's page uses $\eta = \mathrm{diag}(+1,-1,-1,-1)$ (mostly-minus) consistently — the two siblings are now internally consistent but disagree on signature with each other. Recommend picking one signature in §1 and keeping it.
- 3-momentum styling: this page writes $\vec p$ throughout; dirac-equation also uses $\vec p$ but mixes in $\vec p^{\,2}$ with the explicit thin-space, while KG just writes $|\vec p|^2$. Cosmetic but the dirac convention reads slightly cleaner when squaring.
- Imaginary unit in plane-wave convention: KG §3 uses $e^{-i(Et - \vec p\cdot\vec x)}$; dirac §5 uses $e^{-ip\cdot x}$ (4-vector). Both are fine, but KG never introduces the 4-vector shorthand even though §2 has set up $\eta^{\mu\nu}$, so a reader bouncing between pages sees two different look-and-feels for the same plane wave.
- Inline subscripts: "rest energy m²" in the §1 readout is loose — should be either "rest mass-squared $m^2$" or "rest energy $mc^2$" (the readout literally says "rest energy m² = …", which is dimensionally confused even in natural units).

### Undefined jargon
- "on-shell" — §1 first sentence uses it then immediately glosses it parenthetically, so this one is fine.
- "Goldstone boson" appears mid-readout in the §1 widget (`m → 0 limit:  KG → wave equation … the m=0 limit also describes a Goldstone boson, the massless excitation of a spontaneously broken continuous symmetry`) — defined inline, but this is the one place the page invokes a concept the reader has no prereq path to and parks the gloss inside a `readout` element rather than in prose. Schrödinger and Dirac never drop SM-jargon into widget readouts like this. Recommend either pull the gloss into a `.note` block above the widget or shorten the readout to a one-clause mention.
- "Lorenz gauge" in §2 bullet on photon/gluon propagators — used without definition or callback. Schrödinger explicitly walks through `[H, L^2] = [H, L_z] = 0`-type setup in §4 before citing the symmetry; this page uses Lorenz gauge as a naked label.
- "Compton wavelength" in §2 — defined inline as $\lambda_C = \hbar/(mc) = 1/m$, fine.
- "FRW backgrounds" in §6 last bullet — abbreviation introduced cold; should at least be spelled out as "Friedmann-Robertson-Walker."

### Tone mismatches
- Voice is conversational-precise throughout, matching the siblings well. Second-person "we" / "you" usage is sparse but present ("we apply", "We come back to it in §4", "How does the Klein-Gordon equation reduce…").
- One stretch reads more like a textbook recital than the rest: §6 final bullet list ("Pionic atoms / Higgs and effective scalar fields / Path-integral building block / Cosmological perturbations") is four dense terminology-loaded items without the conversational softeners that the same kind of list in schrodinger §4 gets ("hidden $\mathrm{SO}(4)$ symmetry generated by angular momentum together with the conserved Runge–Lenz vector", "ionized electrons"). Not wrong, just feels denser than the rest of the page.

### Missing worked examples
- Every numbered §1–§6 has its own widget. §3 widget is particularly nice (dispersion + group velocity tangent + light cone in one panel). No section is bare.
- §1 widget is a static side-by-side card with a near-trivial $m$ slider — the only thing the slider does is recompute `m²` and toggle a single readout branch. This is the lightest interactive on the page; siblings tend to put the lightest gesture in their final summary section, not their lead. A reader who arrives expecting to "poke" something will tap §1 and get less feedback than they get from §3 or §5. Cosmetic, but worth a future revisit.

### KaTeX macros / formatting
- Helper KaTeX macros block (`\Spec, \Gal, \Hom, \tr, \ad, \ind`) is verbatim copied from the canonical template — KG, Schrödinger, and Dirac all carry the identical block; none of these macros are actually used in any of the three physics pages. That is house standard; flagged only for awareness.
- No locally-introduced macros on the page. Good.
- Boxed formulas use `\boxed{\;…\;}` (with leading/trailing thin spaces) consistently — same idiom as Dirac. Schrödinger does not use `\boxed`. Cosmetic.
- The §1 widget's SVG `text` elements display equations as plain Unicode (`(∂ₜ² − ∇² + m²) φ = 0`, `i∂ₜψ = −∇²/(2m) ψ + Vψ`) instead of KaTeX. This is unavoidable inside SVG `<text>` (KaTeX can't render there), but the unicode subscript `∂ₜ` vs prose `\partial_t` creates a minor inconsistency between widget chrome and surrounding text. Same pattern appears in Dirac's widgets; no action needed.

## Helper-block / widget-chrome hygiene
- Top-of-`<body>` 2D helper block (`$`, `$$`, `SVG`, `ensureArrow`, `drawArrow`, `drawNode`) is byte-identical to the version in category-theory.html / dirac-equation.html. Schrödinger has a typo in its `drawNode` (`{cx,cy:y,…}` — bare `cx` not in scope), so KG is actually cleaner than schrodinger here. Good.
- All five widgets use the canonical `.widget / .hd / .ttl / .hint / .row / .readout` chrome. No ad-hoc class names introduced.
- §3 widget readout is on the long side (`m = … p = … E₊ = … E₋ = … v_g = p/E = … (always |v_g| < 1)    v_φ = E/|p| = … (≥ 1 for massive modes; carries no info)`). Hits ~190 chars on one line; in the narrower viewport this wraps awkwardly. Schrödinger keeps readouts under ~120 chars. Cosmetic.
- §1 widget readout exceeds 350 chars when `m < 1e-3` because it appends the full Goldstone-boson gloss. Trimming or moving the gloss to a `.note` (see Undefined jargon above) would also fix this.
- §5 widget computation comment correctly notes "cross-terms now ∝ cos((p_+ − p_-)x − ph) (E_+ + E_-) — explicit x and φ dependence" — the prose above the widget shows a simplified $2E(|A|^2 - |B|^2)$ form that omits the cross-term. The widget is honest, but a one-line "the widget below uses two distinct momenta so the cross-term gives explicit $x$-dependence" in prose would prevent confusion when prose and widget drift apart.
