# dynamical-systems — pedagogical audit (2026-05)

**Section:** Analysis
**Compared against:** real-analysis, partial-differential-equations

## Summary
Strong, comprehensive page (13 sections, 13 widgets including a registry-backed recurrence-plotter, a 520×340 Julia-set canvas, and a draggable 3D Lorenz attractor) with house-style voice that matches both peers. Two genuine semantic findings: (a) §7 duplicates the period-doubling cascade text from §6 (Feigenbaum constant formula and accumulation values appear nearly verbatim in both), and (b) the page's helper block has drifted from the canonical `drawArrow` defaults. Notation is otherwise clean; jargon is generally well-introduced; one orphan `</p>` markup typo lives inside a §8 `<div class="note">`.

## Findings

### Notation drift
- **High-priority (semantic spelling drift inside the page).** `dynamical-systems.html:825` writes "Sharkovskii's theorem" inline while `dynamical-systems.html:771` (the §5 backlink) writes "Sharkovsky's theorem" and the cross-page peer `mathematical-chaos.html:251,943,944,947,…` consistently uses "Sharkovsky" everywhere (the section anchor is `#sharkovsky`). Pick one transliteration and propagate; the corpus convention is "Sharkovsky".
- `\tr{}A` at line 559 uses empty braces to suppress KaTeX's argument grab; both peers and the macro definition (`\tr → \operatorname{tr}`) call as `\tr A` (no braces) elsewhere. Lines 565–567 then mix `\tr^2`, `\tr<0`, `\tr=0` (no braces, fine). Cosmetic.
- `\mathrm{vol}` (line 1319) vs `\operatorname{vol}` in `real-analysis.html:1046`. `category-theory.md`'s convention is `\mathrm` for fixed semantic decorations, `\operatorname` for operators with arguments — `vol(\Phi_t U)` here is acting on an argument, so `\operatorname{vol}` would match `real-analysis.html`. Cosmetic, low priority.
- `\mathcal{B}` for the Borel σ-algebra (line 1532) is consistent with `measure-theory.html`'s usage — good.
- `\mathbb{R}`, `\mathbb{N}` (braced everywhere — lines 332, 333, 460, 464, 672, 1318, 1469, 1540) match real-analysis (~46 hits) and PDE (~15 hits). No drift.
- `\colon` for typed function colons (`X\colon M\to TM`, `f\colon X\to X`, `T\colon X\to X`, `P\colon\Sigma\to\Sigma`) is used uniformly. Matches both peers.

### Undefined jargon
- **§6 line 846–848 introduces "Mandelbrot set", "filled Julia set", "basilica", and "Fatou's theorem"** with no callback to `complex-analysis.html` (a peer in the same Analysis section). This is the page's biggest jargon-before-definition gap — four named complex-dynamics objects in two sentences with no inline gloss and no `<aside class="callback">`. The §6 callback aside ends with `mathematical-chaos.html#feigenbaum` only; complex-analysis isn't cited. Inline definition or `See also: complex-analysis#julia-mandelbrot` would close the loop.
- **§8 line 1233 says "Chaos, as formalized by Devaney, requires…"** and never cites or expands the Devaney reference (the three-condition definition that follows is *the* Devaney definition, but a first-time reader won't know that). Cosmetic — proper-name attribution is fine — but a `<a>` to `mathematical-chaos.html#devaney` (it exists) would help.
- **§10 line 1407 introduces "Floquet multipliers"** as eigenvalues of $dP(p^*)$ with no further definition or callback. The term lands once and never returns. Either callback to `linear-ODE` / `matrix-exponential` material or fold into a `<strong>` definition.
- **§4 line 672 names "$\omega$-limit set"** and uses it as if defined; this is the first appearance on the page. The Poincaré–Bendixson statement does carry an inline gloss via context (the cases enumerate what an ω-limit set can be), but a one-line "the ω-limit set is the set of all accumulation points of the forward orbit" would help — peers use this kind of inline mini-def consistently (cf. `partial-differential-equations.html:888` defining "weak solution" with an explicit `<strong>Definition</strong>` aside).
- **§9 line 1324 introduces "symplectic form $\omega=\sum dq_i\wedge dp_i$"** with no expansion and no callback to `differential-forms` (which is in the §9 callback list — good — but the wedge product is invoked the same line and the callback link is to `differential-forms.html#wedge`, also good). This one is actually well-handled; flagged here as a positive example.
- **§7 line 1169 mentions "needs $\mathbb{Z}/2$-symmetry"** parenthetically inside the pitchfork-bifurcation row of the normal-forms table. No callback to abstract-algebra. Cosmetic — $\mathbb{Z}/2$ is universally familiar — but worth noting.
- **§13 line 1611 mentions "subcritical Hopf bifurcation"** with no internal anchor back to §3 (where Hopf normal form is introduced) or §7 (where it appears in the table). Internal `<a href="#bifurcation">` link would be cheap.

### Tone mismatches
- Voice matches peers throughout (third-person + occasional "you", interleaved `<div class="note">` theorem boxes, "things to notice" lists). The page is closer to PDE's tone (terse-but-warm theorem-then-example beat) than to real-analysis (longer narrative paragraphs).
- **One stylistic outlier:** §4 line 672 ends "if $\omega(\gamma)$ contains no fixed point, **it IS a periodic orbit**." All-caps for emphasis is the only such use on the page; the corpus convention (cf. `real-analysis.html:1540` and `partial-differential-equations.html:467`) is `<strong>` or italic emphasis. Cosmetic; replace with `<strong>is</strong>` or `<em>is</em>`.
- §1 lines 340 ("Two vector fields, same phase space — very different stories.") and §6 line 825 ("the picture is not a uniform sea of chaos") are good examples of the warm conversational voice the template encourages — keep.

### KaTeX macros / formatting
- **Markup bug (low-priority — KaTeX-adjacent).** `dynamical-systems.html:1244` (the §8 "Higher dimensions" note) closes its body paragraph with `</p>` but the note was opened with `<div class="note"><strong>Higher dimensions.</strong>` and never opened a `<p>`. So line 1244 emits an orphan `</p>` immediately before line 1245's `</div>`. Browsers will silently auto-close this; not a render bug, but contrast with `partial-differential-equations.html:463–471` which uses `<div class="note"><p><strong>…</strong>…</p></div>` consistently. Either drop the orphan `</p>` or wrap the body in `<p>`.
- **Helper-block drift — semantic.** The `drawArrow` defaults differ from the canonical `category-theory.html`:
  - `category-theory.html:212–213`: `pad1 = opts.pad1 ?? 14, pad2 = opts.pad2 ?? 16` (intended for **node-to-node** arrows that pad away from the circle stroke).
  - `dynamical-systems.html:210–212`: `pad1 = opts.pad1 ?? 0, pad2 = opts.pad2 ?? 8` (only an 8-pixel head-pad, no tail-pad).
  This is a real semantic deviation: AGENTS.md §"Page-global helpers" says "**copy verbatim** from category-theory.html — do not rewrite". The override is presumably because dynamical-systems doesn't draw node-graphs anywhere — but the deviation will silently bite the next person who copies a node-graph widget here. **Recommend:** restore the canonical defaults and let any specific call-site pass `pad1: 0, pad2: 8` explicitly.
- **One SVG attribute typo:** line 1386 emits `fillOpacity:0.25` (camelCase JS property name) instead of the SVG attribute name `'fill-opacity':0.25`. Browsers handle camelCase via the JS DOM property only; on attribute serialization (which `setAttribute` does inside `SVG()` helper line 192) the attribute is literally written as `fillOpacity="0.25"`, which SVG ignores. The blob-volume-evolution widget (§9 `#w-div`) therefore renders the forward-image polygon with default fill-opacity 1 (opaque yellow) instead of the intended 0.25 — confirming visually that the inner blob is hidden. Compare to `partial-differential-equations.html:585` which correctly uses `'fill-opacity':0.16`. **Real bug, low-medium priority.**
- No locally redefined macros; the macro block (lines 38–45) is byte-identical to peers.
- KaTeX uses both `$…$` / `$$…$$` and `<p style="text-align:center">$…$</p>` for displays — a mild inconsistency. `partial-differential-equations.html` uses raw `$$` more often; `real-analysis.html` mixes both. No drift (matches the corpus mix).
- `\bmod` (lines 1242, 1471, 1540) is used correctly; `\dot`, `\ddot`, `\Phi`, `\sigma_s`, `\Re`, `\Im` all use built-in KaTeX. Macro discipline is clean.
- `\bar f` (line 1536) for the time-average limit. Consistent with house style.
- Widget chrome (`.widget`, `.hd`, `.ttl`, `.hint`, `.row`, `.readout`, `.note`, `.small`) is used uniformly across all 14 widgets — no ad-hoc classes. The `<canvas>` widget at line 852 wraps in the standard `.widget` shell with a `.row` for sliders and a `.readout`, matching the other interactives.
- All 13 sections carry a `<div class="quiz" data-concept="…">` placeholder; concept ids match `concepts/dynamical-systems.json` conventions (`dyn-orbits-flows`, …). Anchor contract intact.
