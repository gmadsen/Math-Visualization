# class-field-theory — pedagogical audit (2026-05)

**Section:** Number theory
**Compared against:** algebraic-number-theory, frobenius-and-reciprocity

## Summary
The page is largely well-built and matches the section's voice and chrome, but two of nine sections lack any worked widget, the Frobenius operator is written three different ways across the page, and one display-math formula trails off in literal `\cdots`. These are mostly minor polish, with one semantic-drift item (Frobenius notation) worth addressing.

## Findings

### Notation drift
- **Frobenius operator is written three ways on the same page.** Display math uses `\operatorname{Frob}_\mathfrak{p}` (line 737, 1035), but the widget caption at line 771 and the §8 worked-example body (line 1037+) use `\mathrm{Frob}_p`, while readouts emit plain `Frob_p` (lines 797, 807, 818, 836, 849, 1095). Reference `frobenius-and-reciprocity.html` is uniformly `\mathrm{Frob}_\mathfrak{P}` / `\mathrm{Frob}_p` (lines 667, 672, 675, 788, 808). Recommend: pick `\mathrm{Frob}` everywhere in math (matches the Frobenius reference page) and reserve `\operatorname{Frob}` only if a true CFT-specific reason exists. Semantic, low-medium priority — readers may briefly think the two glyphs mean different things.
- **Class-group symbol mismatch with reference.** Target uses `\operatorname{Cl}(K)` (lines 492, 494, 626, 751); `algebraic-number-theory.html` uses `\mathrm{Cl}(\mathcal{O}_K)` (lines 530, 720, 722, 741). Both exist on the same Number-theory shelf. Cosmetic; settle on one (the ANT spelling makes the ring of integers explicit and is closer to standard textbook usage).
- **Maximal abelian extension exponent.** Target writes `\mathbb{Q}^{\mathrm{ab}}` (line 326) and `K^{\mathrm{ab}}` (lines 903, 1149) but also `G_K^{\mathrm{ab}}` once (line 1149) and the readout text `G_K^ab` (line 1199, 1224). `frobenius-and-reciprocity.html` does not use this symbol so target is the de-facto standard-setter; just be consistent — choose `\mathrm{ab}` and stick to it (already mostly done).
- **`\sigma_p` versus `\operatorname{Frob}_p` ambiguity inside §1 and §4.** Line 322 introduces `\sigma_a` for the cyclotomic Galois action; line 751 silently equates "Artin map is $p\mapsto\sigma_p$" with `\operatorname{Frob}_p`. The two-name convention is fine but never spelled out — flag as a low-priority consistency item.

### Undefined jargon
- **"Hecke characters" used before any definition.** Line 1127 (§9 dictionary table) says `Finite-order characters of $C_K$ (Hecke characters)`, and line 1130 repeats `Hecke characters $\chi: C_K\to\mathbb{C}^\times$`. The word "Hecke" never appears earlier on the page nor is there a callback to `dirichlet-series-euler-products` or another defining topic. First-time readers see a new named object on the analytic side with zero scaffolding.
- **"Größencharaktere" appears in a widget readout with no introduction.** Line 1207: `'(= Größencharaktere)'`. This is a pleasant historical aside but functions as undefined jargon in a SVG readout — most readers won't know it's a synonym for Hecke characters.
- **"Higher ramification filtration" and "Swan conductor" used without definition.** Line 1005: `…how deeply $\chi$ restricts to the higher ramification filtration of $\mathfrak{p}$`. Line 1011: `…wildly ramified primes contribute with higher multiplicity via the Swan conductor.` Both terms are introduced and used in the same paragraph with no definition, callback, or hand-waving gloss. §7 is the most jargon-dense section by far.
- **"Connected component of $1$" appears as the kernel of $\theta_K$ in the boxed theorem.** Line 905: `…with kernel the connected component of $1$.` For a topological group, this is a precise condition, but the page never establishes that $C_K$ has a topology, much less identifies the connected component. ANT and frobenius-and-reciprocity don't reach this depth, so the target page must do its own scaffolding.
- **"admissible congruence subgroup" appears once with no definition.** Line 980: `…any admissible congruence subgroup is actually the kernel of the Artin map…`. The classical Takagi formulation needs the word "admissible" defined (essentially: $H$ contains $P_K^\mathfrak{m}$ for some modulus); the boxed statement that follows defines the right notion implicitly but the prose drops "admissible" cold.
- **"$\ell$-adic reps from cohomology"** in widget 7 (line 1231) is undefined. Same widget table introduces "modular forms, Maass forms" without callbacks; modular forms gets a link in the prose at line 1150 but Maass forms does not.

### Tone mismatches
- **§7 (conductor-discriminant) reads as a dense paragraph dump rather than the discovery voice the rest of the page maintains.** Lines 1005–1011 are two long paragraphs of formal definition-then-formula with no widget, no "let's compute", no example. Compare to `algebraic-number-theory` §4 ramification, which gives a trichotomy table, the Kummer–Dedekind algorithm, and a widget; or `frobenius-and-reciprocity` §6 Chebotarev which gives a numeric "watch the bars settle" experiment. §7 is the page's coldest section.
- **§6 (Takagi) similarly drifts into dry-textbook voice** for the entire section: a boxed theorem with two prose nested-list bullets, then one closing paragraph saying "this gives an algorithm" without actually executing the algorithm on a concrete `K` and `G`. The neighboring sections all have a worked widget; §6 simply does not.
- **The Langlands dictionary widget (§9) is over-dense.** The HTML `<div class="dict">` table at lines 1122–1144 packs 7 rows of comparison labels including phrases like `$\mathrm{GL}_n(\overline{\mathbb{Q}}_\ell)$` and "Weight-2 cusp forms" that have not been mentioned. Category-theory's tone for big dictionaries is "build it up incrementally with the toy"; §9 dumps it whole. The toggle widget below (`w-langlands`) softens this somewhat but the dict table still front-loads the jargon.

### Missing worked examples
- **§6. Takagi's existence theorem — no widget at all.** Section consists of one prose paragraph + one boxed theorem + one closing paragraph. Reference §3 (Hilbert class field) and §5 (ray class) both ship a widget; §6 should at minimum reuse the conductor slider with an "and conversely, every subgroup gives a field" toggle, or a small enumerated list "for K = Q(i), here are the abelian extensions of conductor up to 12".
- **§7. The conductor-discriminant formula — no widget at all.** This is the most computational result on the page (literally a product formula) and would benefit from a widget that picks `Q(zeta_n)` for small `n`, lists the Dirichlet characters mod `n`, shows each character's conductor, and verifies the product equals the disc. Currently the section just states the formula and immediately invokes Swan conductors.
- **§9 has two widgets but neither computes anything.** `w-dict` is a static comparison table; `w-langlands` is a 2-state toggle that swaps dictionary cards. Neither lets the reader poke at, say, a 2-dim Galois rep or a modular form coefficient. Cosmetic — §9 is meant to be a coda, not a computational section, but the contrast with §1–§5 is sharp.

### KaTeX macros / formatting
- **Truncated formula at line 1011.** The display reads `\operatorname{disc}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) = \prod_{p\mid n} p^{\,\varphi(n)(1-\tfrac{1}{p-1})/\cdots}` — the exponent literally ends in `/\cdots`. This is either a half-finished placeholder or a typesetting bug that escaped review. **Highest-priority semantic fix on the page.**
- **No new `macros:` entries vs reference.** Target's KaTeX loader at lines 22–28 is byte-identical to `algebraic-number-theory` and `frobenius-and-reciprocity`: only `\Spec`, `\Gal`, `\Hom`, `\tr`, `\ad`, `\ind`. Good — no rogue local macros.
- **Helper block at top of `<body>` is verbatim** (lines 200–289 vs ANT 187–252 vs frobenius 200–449). The number-theory-helpers block adds `legendre`, `eulerPhi`, `divisors`, `primesUpTo`, `gcd`, `mod`, `isPrime` — same set as ANT/frobenius. No drift.
- **Widget chrome is conformant.** Every `<div class="widget">` carries the canonical `<div class="hd"><div class="ttl">…</div><div class="hint">…</div></div>` skeleton plus `.row` / `.readout`. No ad-hoc classes introduced. The `.dict`, `.tower`, `.chip` classes used in §9 / §3 / §2 are defined locally in the page's `<style>` block (lines 119–126), which is acceptable per house convention but worth noting that they don't appear in `category-theory.html`'s shared chrome — could be lifted if reused elsewhere.
- **One stray HTML-entity in an SVG `<title>`.** Line 337: `<title>Cyclotomic tower &amp;amp; abelian subfields</title>` has the ampersand double-encoded (`&amp;amp;` instead of `&amp;`). Cosmetic; surfaces as `&amp;` in tooltips.
- **Inline `\GL_1` macro is used at line 781** in a backlink (`Class field theory as Langlands for $\GL_1$`) but `\GL` is not in the local macros block. Will rely on KaTeX's `\GL` if defined as auto-rendered text or fall back to a render error toggled off by `throwOnError:false` — quietly emits red glyph. Recommend either adding `\GL` to the local macros or rewriting as `\mathrm{GL}_1` to match the rest of the page (line 1135 already uses `\mathrm{GL}_n`).

## Severity
minor polish (with one must-fix semantic glitch: the truncated `\cdots` exponent in §7's display formula, and the tri-form Frobenius notation worth unifying in the same pass)
