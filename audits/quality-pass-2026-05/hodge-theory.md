# hodge-theory — pedagogical audit (2026-05)

**Section:** Algebraic geometry
**Compared against:** algebraic-de-rham-cohomology, kahler-geometry

## Summary
The page reads as a polished overview essay rather than a Brilliant-style notebook: prose voice and notation are largely consistent with the two references, but the entire topic ships with zero interactive `<div class="widget">` elements while both peers carry 4–5 each (Hodge-diamond explorer, Lefschetz pairings, Fubini–Study potential, proof-scrubbers). The two existing SVGs are static legends, so every section is "definition + slogan + maybe one diagram" with nothing to poke.

## Findings
### Notation drift
- Macro `\dR` is defined (`'\\dR':'\\mathrm{dR}'`) and used in §3 (`H^{p+q}_\dR(X)`), but `algebraic-de-rham-cohomology.html` writes the same object as `H^n_{dR}(X/k)` in plain `_{dR}` throughout (e.g. `$H^n_{dR}(X/k) := \mathbb{H}^n(X, \Omega^\bullet_{X/k}).$`). Cosmetic, but the same notebook-page pair disagrees on a central symbol — settle on one form (`\dR` would be the cleaner choice if propagated).
- §3 uses `\mathrm{im}(\mathbb{H}^n(X, \sigma^{\ge p} \Omega^\bullet_X) \to H^n_\dR(X))` with no `\mathcal{O}_X`-style decoration on the truncation, while the de-Rham reference consistently writes `\sigma^{\ge p} \Omega^\bullet_{X/k}` with the `/k` subscript. Low-severity but the relative-base disappears silently when the target page introduces it.
- §6 uses `\CH^p(X)` (macro `\operatorname{CH}`); the see-also link in the same callback labels it `Chow groups $A_*(X)$`. Two different name-conventions for the same object on one page. Cosmetic; consider standardising on `\CH^*` since that's what the body uses.
- The `/k` base field is silently dropped throughout: §1 writes `\Omega^1_X`, `\Omega^p_X`, `\Omega^\bullet_X`, while the de Rham reference always carries `_{X/k}` and only drops it inside a fixed scope. Semantic-low (everything is over $\mathbb{C}$ here), but inconsistent with the sister page that the callbacks point to.

### Undefined jargon
- §1 hero paragraph uses *"Deligne's mixed Hodge structures"* in the lead sentence ("…how it organises invariants of singular and non-compact varieties (Deligne's mixed Hodge structures)…") with no callback or definition until §5. A reader linearly scrolling sees the term ~80 lines before it is unpacked. Acceptable foreshadowing if rephrased ("see §5"), but currently load-bearing in the hero.
- §3 uses *"hypercohomology"* in `\mathbb{H}^n(X, \sigma^{\ge p} \Omega^\bullet_X)` with no in-page definition and no callback to `sheaf-cohomology.html#hypercohomology` (the de Rham reference at least anchors against `Hypercohomology and the Čech double complex` in its callback bullet). First offending sentence: *"Equivalently, the Hodge filtration $F^p H^n_\dR(X) := \mathrm{im}(\mathbb{H}^n(X, \sigma^{\ge p} \Omega^\bullet_X) \to H^n_\dR(X))$ is well-defined…"*
- §3 first paragraph references *"the de Rham complex $\Omega^\bullet_X$ has a 'stupid' filtration $\sigma^{\ge p}$"* without ever defining the *stupid / trivial truncation* (the de Rham reference devotes a full scrubber step to it). Quote: *"The de Rham complex $\Omega^\bullet_X$ has a 'stupid' filtration $\sigma^{\ge p} \Omega^\bullet_X = (0 \to \cdots \to 0 \to \Omega^p \to \Omega^{p+1} \to \cdots)$ — kill everything in degree $< p$."* The parenthetical is the only definition.
- §4 introduces *"Tannakian"* / *"neutral Tannakian category"* / *"Tannakian fundamental group"* / *"fiber functor"* / *"Mumford-Tate group"* in a single `<aside class="note">` with no prereq callback. Mumford-Tate in particular is then load-bearing in §6 (`G_{\mathrm{mot}}(\mathbb{Q}) \twoheadrightarrow \MT(X)`) and §8 with no further definition.
- §5 uses *"abelian (not semisimple — extensions are nontrivial), Tannakian"* without defining "semisimple" in a Tannakian context (it was used in §4 too, in passing).
- §6 first bullet under "Equivalent reformulations" introduces `G_{\mathrm{mot}}(\mathbb{Q})` (the motivic Galois group) with the parenthetical *"…makes contact with motives"* but no definition or anchor; the one in-page link is to `motives.html#motivic-galois`, which the rest of the corpus does not currently host.
- §8 references *"Voevodsky's $\mathsf{DM}(\mathbb{Q})$"*, *"Huber, Bondarko"*, and *"triangulated avatar"* with no definitions or callbacks — these are aside-text deep-dives, but the page never tells a reader what `\mathsf{DM}` *is*.
- §6 callback to `motives.html` and §8 inline link to `./motives.html#motivic-galois` — `motives.html` does not exist in the corpus (verified via the audits-2026-05 file listing). Semantic high: the conjecture's "Tannakian" reformulation is gated on a 404.

### Tone mismatches
- §3 contains a raw transcription glitch: *"Defined purely algebraically over the field $X$ is defined over (the filtration is rational; the conjugation-symmetric splitting is not)."* — sentence does not parse; reads like a copy-paste artifact. Fix to *"Defined purely algebraically over the field $X$ is defined over (the filtration is defined over $k$; the conjugation-symmetric splitting is not)."* or similar. High-priority.
- §6 `<aside class="bad">` opens with *"Open since 1950."* in bold and then dives straight into a 5-line list of partial results — this is the page's most prominent narrative beat (a Clay Millennium problem) and it currently reads as terse compressed bibliography rather than a Brilliant-style "here's the human story". The two reference pages reserve `bad`/`ok` asides for clearly-flagged failures or theorems and use prose paragraphs for narrative beats.
- §8 paragraph *"Modulo the standard conjectures + Hodge, motives over $\mathbb{Q}$ would be entirely determined by their Hodge realizations — the Tannakian formalism would collapse to 'studying motives is studying their Hodge structures.'"* mixes two undefined-on-page concepts ("standard conjectures", "Tannakian formalism") into a sentence that *sounds* explanatory but is opaque without the prereqs. Compare kahler-geometry §3 where every named object (`\Lambda`, `L`, `H = [L,\Lambda]`, `\mathfrak{sl}_2`) is unpacked in the same paragraph it appears.
- "Connections" closing section (§9) has no `id` matching the TOC anchor `#connections` issue is fine (the `<section id="connections">` tag is present), but the section is unnumbered ("Connections" without a leading "9.") while the TOC entry says "9 Connections". Minor cosmetic drift from kahler-geometry/algebraic-de-rham-cohomology, both of which use a numbered `7. Connections` `<h2>`.

### Missing worked examples
- **§1 (Why Hodge structures?)** — pure motivation + slogan; no concrete computation. The reference pages both seed §1 with at least one calculable invariant (kahler-geometry §1 has the `(p,q)`-bigrading explorer widget; de-Rham §1 has the proof-scrubber walking through `\Omega^1` for $\mathbb{A}^1$, $\mathbb{P}^1$, $\Spec k[\epsilon]/(\epsilon^2)$).
- **§2 (Hodge decomposition)** — the static SVG diamond is decorative, not interactive (the labels `q`, `p_g`, `h^{1,1}` are baked in). kahler-geometry §3 ships an interactive Hodge-diamond explorer with a slider for $n$; algebraic-de-rham-cohomology §5 ships the click-cell diamond with Serre/conjugation arrows. The target's diamond is a two-line legend with no toy. **High-priority gap** — this is the section that *demands* a widget across the whole notebook.
- **§3 (Hodge filtration)** — defines `F^p`, the spectral sequence, `E_1`-degeneration, and `\mathrm{gr}^p_F` in 4 paragraphs with zero numerical example. algebraic-de-rham-cohomology §4 walks through `F^\bullet` on $\mathbb{P}^1$ ("$F^0 H^0 = F^1 H^2 = \mathbb{C}$, all other steps trivial") and ships a proof-scrubber. Recommend adding the same `\mathbb{P}^1` toy or an elliptic-curve `H^1 = F^0 \supsetneq F^1 = H^{1,0} \supsetneq F^2 = 0`.
- **§4 (Pure Hodge structures as a category)** — Tate-twist arithmetic ($\mathbb{Q}(1)$ has weight $-2$, type $(-1,-1)$, realized as $2\pi i \cdot \mathbb{Q}$) is *exactly* the kind of thing a button-stepper could illustrate, and the Mumford-Tate aside begs for a small worked example (e.g. MT group of a CM elliptic curve = $\mathbb{T}_K$ vs. generic = $\mathrm{GL}_2$). Currently zero examples.
- **§5 (Mixed Hodge structures)** — has the static MHS-stack SVG (decorative) and one prose example ($H^1(\mathbb{C}^*) = $ extension of weight 2 by weight 0). The example is good but un-poked; a minimal interactive (e.g. slide between "compact + smooth → pure" and "non-compact / singular → mixed") would match section peers.
- **§6 (Hodge conjecture)** — pure statement + history + reformulations. No worked Lefschetz $(1,1)$-example (e.g. the cycle class of a degree-$d$ curve in $\mathbb{P}^2$ as the generator of $H^{1,1}(\mathbb{P}^2; \mathbb{Q})$).
- **§7 (Period domains)** — names the Siegel upper half-space, the K3 period domain, and Griffiths transversality but never computes a single period or shows a single picture of $\mathfrak{H}_g$ for $g = 1$. de-Rham §3 has a worked $\int_\gamma \frac{dz}{z} = 2\pi i$ proof-scrubber; the analogous *period of an elliptic curve* would slot in here perfectly.
- **§8 (Motivic realization)** — abstract narrative; no example. (Acceptable as a "tying threads" section, but the page never has *any* concrete period or cycle calculation, so this is part of a pattern.)

### KaTeX macros / formatting
- The macro block defines `\HS` and `\MHS` as `\mathsf{HS}` / `\mathsf{MHS}` — neither reference page uses `\mathsf` for category names; algebraic-de-rham-cohomology and kahler-geometry don't define analogous macros at all (they spell categories out as `\mathrm{D}^b(\cdot)`, `\mathrm{QCoh}(X)`, `\mathrm{Pic}(X)`). The `\mathsf` choice is fine on its own but introduces a third font convention; flag for global consistency. category-theory.html uses neither.
- Macro `\Hdg` (`\mathrm{Hdg}`) and `\MT` (`\mathrm{MT}`) are local-only and don't appear in either reference. Acceptable since `Hdg` and `MT` are page-specific subjects, but `\MT(X)` shadows a common shortcut for "Mumford-Tate" with no anchor in the page text introducing it.
- `\CH` is defined as `\operatorname{CH}` here; `intersection-theory-chow.html` (linked in the §6 callback) is the canonical home for that notation — verify the chosen rendering matches that page's convention. Cosmetic.
- §2 SVG hardcodes raw text labels `q`, `p_g`, `h^{1,1}`, `p_g`, `q` without `$…$` delimiters in `<text>` elements (e.g. `<text … font-weight="600">q</text>`). KaTeX auto-render only touches DOM text; SVG `<text>` is excluded. The labels render as plain glyphs — `p_g` literally shows as "p_g" (subscript not rendered). The companion captions (`<text … >$h^{2,0}$</text>`) get LaTeX'd because they're aside the SVG and inside a `<text>` ancestor that auto-render walks (actually they don't render either — KaTeX skips inside `<svg>`). **High priority** — verify in browser. The reference pages route any LaTeX label in an SVG either through `<foreignObject>` or by resolving the symbol to a static glyph; this page does neither.
- Helper `<script>` block (lines 188–240) is verbatim from category-theory.html. ✓ ok.
- Widget-chrome hygiene is N/A because the page has no widgets at all — confirmed via grep. The `widget` class only appears in the `<style>` block and in `display-prefs` CSS.
