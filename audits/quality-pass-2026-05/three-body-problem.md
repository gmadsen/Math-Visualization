# three-body-problem — pedagogical audit (2026-05)

**Section:** Mathematical physics
**Compared against:** hamiltonians-classical-mechanics, general-relativity

## Summary
Six well-built widgets, six worked sections, voice and KaTeX delimiters fully aligned with the Mathematical-physics peers. The only meaningful issue is duplicated callback asides (a "Prereq" hand-block immediately followed by an autogenerated "See also" block of the same content) in three sections; everything else is minor polish.

## Findings
### Notation drift
- Position vectors are written bare (`r_1, r_2, r_3 \in \mathbb{R}^3`, `\ddot r_i`) rather than with `\vec{}` or boldface — consistent across the page and harmonious with the peers (e.g. `R^\rho{}_{\sigma\mu\nu}` in general-relativity is also bare-symbol). No drift, intentionally minimal.
- `\mathbb{R}^3`, `\mathbb{Z}`, `\mathbb{T}^n` all spelled out long-hand — matches hamiltonians-classical-mechanics exactly (no local `\R`/`\Z` macros invented). Good.
- "centre of mass" used in §1 prose but readout glyph uses bare `R` (line 287) — the symbol-name `R` is not introduced in display math; reader has to infer from the prose. Cosmetic.
- §2 effective potential uses `U_{\mathrm{eff}}` (line 475) and §1 uses `\dot r` for dotted positions — both standard, both matching hamiltonians-classical-mechanics's `\mathrm{const}` / `\dot q^i` style. No drift.

### Undefined jargon
- "homographic motions" (§3, line 646) appears parenthetically with no definition or callback. First-time reader stalls.
- "choreography / choreographies" (§3 widget caption, line 660) is used as a load-bearing term — the figure-eight is "the only currently known choreography… that is not a relative equilibrium" — but the term is never defined; only inferred from the parenthetical "every mass follows a translate (or the same copy) of one curve". Should be promoted to an explicit one-line definition before that sentence.
- "Birkhoff zones" (§5 prose, line 866) is used before it is described. The KAM widget caption later mentions "Birkhoff chain of islands" but no definition links the two. Compare hamiltonians-classical-mechanics §5, where the same term is also used after the KAM display — both pages share this gap, so this is mild peer drift rather than unique to target.
- "Arnold diffusion" (§5 note, §6 prose, line 866 and 987) is invoked twice as a load-bearing concept without a one-line gloss; reader is expected to take it on faith.
- "Greene's residue criterion" (§5 widget caption + readout, line 876, 941) named twice with no gloss; can stay parenthetical but is currently leaning on un-shared expert vocabulary.
- "near-rectilinear halo orbits" (§6 table, line 978) — "near-rectilinear" not glossed. Probably fine for a table cell.
- "Laplace chain" (§6, line 987) — load-bearing for a parenthetical example, not glossed.
- §6 prose says "the homoclinic web is a transit network" (line 971) — "homoclinic" was introduced in §4 but "homoclinic web" is a slightly different object (the web of intersecting manifolds across multiple Lagrange points); ambiguous lift.

### Tone mismatches
- Voice is conversational-precise throughout, matching peers (e.g. "Three masses, gravity, and the ten classical integrals — and the surprise that what's left is enough to invent dynamical systems" mirrors hamiltonians-classical-mechanics's "Phase space is a symplectic manifold and physics is its geometry"). No drift.
- §1 closing sentence "Newton (1687) wrote down the equations; the next two centuries were a search for explicit solutions, and the next century after that was a forced retreat from that search." — strong narrative, consistent with the storytelling cadence of general-relativity. Good.
- §5 opener "Poincaré's tangle is a worst-case scenario: chaos is generic. But planetary orbits have been quasi-stable for billions of years — so what saves them?" — exemplary Brilliant-style hook; matches the peers' rhythm.
- §6 closing prose drifts toward dense citation listing ("Wisdom, Murray–Holman", "Koon, Lo, Marsden, and Ross around 2000", "Trappist-1's $8:5:3:2:3:4:3$ Laplace chain") without much narrative; mild "wall of references" texture, but contained.

### Missing worked examples
- All six numbered sections have at least one widget. §1 ships a 4-preset N-body simulator, §2 has the Lagrange-points/effective-potential widget, §3 the three-special-solutions choreography demo, §4 a horseshoe-symbol-itinerary widget, §5 the KAM-tori-vs-perturbation widget, §6 the halo/tadpole orbit widget. Coverage is complete.
- The §4 horseshoe widget (`tbp-h-step` / `tbp-h-back` buttons) does not actually advance an iteration — both buttons just bump the iteration slider, and "step f" / "step f^{-1}" are functionally identical (both end up redrawing from `iter.value`). The label promises a forward/inverse action that doesn't exist. Semantic drift on the widget chrome — interactive controls misrepresent the dynamics.
- The §1 simulator's "generic 3-body" preset is not labelled as chaotic in the widget itself — only the readout shows preset name. A `note` line below would close the loop with the §4 chaos discussion.

### KaTeX macros / formatting
- No locally-introduced macros beyond what the head loader provides. `\Spec`, `\Gal`, `\Hom`, `\tr`, `\ad`, `\ind` are all section-shared and untouched. Good.
- Delimiters are exclusively `$…$` and `$$…$$` — no stray `\(…\)` or hand-rolled wrappers. Matches house convention.
- Line 287's `<code>r₁=(0.97,−0.243)</code>` etc. uses Unicode subscripts and a Unicode minus inside `<code>`, which is fine since it is inside `<code>`, not a math span; consistent with the peers' use of `(q,p)` plain text in readouts.
- §6 table cell line 980: `$\sim 10^4$ bodies librating` mixes `\sim` (math) with the plain-text "bodies librating" — standard; matches peers.
- General-relativity uses a `\boxed{…}` for the Einstein equation; this page does not, and should not — boxed display would not fit the gentler theorem-spotlight usage here.

## Helper-block / widget-chrome hygiene (out-of-band finding)
- **Duplicated callback asides** (high priority — semantic drift): §2 (lines 620–622 + 624–630), §4 (lines 832–835 + 837–844), and §5 (lines 948–950 + 952–959) each carry a hand-authored `<aside class="callback"><div class="ttl">Prereq</div>` block immediately followed by an auto-generated `<!-- callback-auto-begin --> <aside class="callback"><div class="ttl">See also</div> … <!-- callback-auto-end -->` block carrying the same link(s). Reader sees the same "Hartman–Grobman" / "Poincaré section" / "Hamiltonian flows" link rendered twice in succession. The audit-callbacks fence pattern (per AGENTS.md) is meant to be the sole owner; the bare hand-aside should be removed from `content/three-body-problem.json` so the auto-block is the only one rendered.
- Widget chrome (`.widget`, `.hd`, `.ttl`, `.hint`, `.row`, `.readout`, `.note`, `.small`) is used uniformly and matches both peers. No ad-hoc classes.
- Helper script block at top of `<body>` (lines 187–239) is byte-identical to hamiltonians-classical-mechanics — verified by spot-check of `$`, `$$`, `SVG`, `ensureArrow`, `drawArrow`, `drawNode`. Good.
