## Wrong / dubious claims

- **dirichlet-unit-theorem.html:515 — Cattle problem digit count.** Page says Pell with $d=4729494$ has smallest solution "$\sim 10^{206544}$ digits". The classical result (Amthor 1880) is that the smallest total-cattle solution **is** roughly $7.76\cdot 10^{206544}$ — i.e. a number with ~206545 digits, not a number with $10^{206544}$ digits. Off by an exponential.
- **dirichlet-unit-theorem.html:496–500 — CF gives "the fundamental unit".** For $d\equiv 1\pmod 4$ the CF method on $\sqrt d$ produces the fundamental unit of $\mathbb{Z}[\sqrt d]$, which is generally a *cube* (not a square) of the fundamental unit of $\mathcal{O}_K=\mathbb{Z}[(1+\sqrt d)/2]$. Verified: for $d=5$, CF gives $2+\sqrt5=\varphi^3$; for $d=13$, CF gives $18+5\sqrt{13}=((3+\sqrt{13})/2)^3$. The page's table column 4 lists the genuine $\mathcal{O}_K$ fundamental unit (e.g. $(1+\sqrt5)/2$, $(3+\sqrt{13})/2$), so column 4 disagrees with what the algorithm in lines 496–500 actually outputs. The "(up to a square if −1 Pell unsolvable)" caveat addresses a different gap.
- **dirichlet-unit-theorem.html:561 — S-unit absolute value typo.** "$|u|_v=-v(u)\log Nv$" equates a multiplicative absolute value with a logarithm. Should be either $\log|u|_v=-v(u)\log Nv$ or $|u|_v=(Nv)^{-v(u)}$.
- **dirichlet-unit-theorem.html:331 — Q(ζ_n) "cyclotomic units".** Calling $\mathcal{O}_K^\times$ "cyclotomic units" conflates the full unit group with the proper finite-index subgroup of cyclotomic units (generated by $(1-\zeta^a)/(1-\zeta)$ and roots of unity). Minor labelling issue.

## Underspecified or unverifiable claims

- **dirichlet-unit-theorem.html:339 — Minkowski threshold "$2^{r_1}\pi^{r_2}\sqrt{|\Delta_K|}$ (twice the covolume of $\mathcal{O}_K$)".** Whether this matches Minkowski's convex-body theorem depends on the convention for Haar measure on $K_\mathbb{R}=\mathbb{R}^{r_1}\times\mathbb{C}^{r_2}$. Under the Marcus convention (Lebesgue on $\mathbb{C}\cong\mathbb{R}^2$, $\mathrm{covol}(\mathcal{O}_K)=2^{-r_2}\sqrt{|\Delta_K|}$), the box-volume threshold is $2^{r_1+r_2}\sqrt{|\Delta_K|}$ — no $\pi$. The $\pi^{r_2}$ shows up only when measuring a *complex disk* convex body. The phrase "twice the covolume" is also off by a factor: $2\cdot\mathrm{covol}=2^{1-r_2}\sqrt{|\Delta_K|}$. Without an explicit convention statement, this paragraph is hard to read as correct.
- **dirichlet-unit-theorem.html:331 — Q(ζ_n) signature (0, φ(n)/2).** Implicitly assumes $n\ge 3$; trivially false for $n=1,2$. Acceptable in context.
