## Wrong / dubious claims

- **algebraic-number-theory.html:326** — "$\omega = \tfrac{-1+\sqrt{-3}}{2}$ a primitive sixth root of unity". The number $(-1+\sqrt{-3})/2 = e^{2\pi i/3}$ is a primitive **third** root of unity (order 3), not sixth. The primitive 6th root of unity is $(1+\sqrt{-3})/2 = e^{\pi i/3} = -\omega^2$. The unit group $\mathcal{O}_K^\times$ has order 6 because it contains $\pm 1$ and $\pm \omega, \pm \omega^2$, so it is generated by $-\omega$ (a primitive 6th root); but $\omega$ itself is not a 6th-root generator.
- **algebraic-number-theory.html:1311** — Repeats the same false formula in the readout: `'μ_K = ⟨ζ₆⟩ ≅ Z/6  (ω = (-1+√-3)/2)'`. The formula identifies $\zeta_6 = \omega$, but those are different roots of unity. Should read $\zeta_6 = (1+\sqrt{-3})/2$ or `μ_K = ⟨−ω⟩` with $\omega = (-1+\sqrt{-3})/2$ a primitive 3rd root.
- **algebraic-number-theory.html:1228** — Widget labels e^{iπ/3} (k=1) as "ω". Combined with the prose definition $\omega = (-1+\sqrt{-3})/2 = e^{2\pi i/3}$, the labeling is inconsistent: with the prose's $\omega$, the k=1 dot should be labelled $-\omega^2$ (or $\zeta_6$), and $\omega$ itself should sit at k=2. Currently the widget effectively redefines $\omega := e^{i\pi/3}$, contradicting line 326/1311.
