## Verified claims (sections)

- **§1 Almost complex structure.** $J^2=-\mathrm{id}$, even-real-dim necessity, $TM\otimes\mathbb{C}=T^{1,0}\oplus T^{0,1}$ as $\pm i$-eigenspaces of $J$, induced $(p,q)$-bigrading, $d=\partial+\bar\partial$ iff integrable. Newlander–Nirenberg (1957) with the Nijenhuis tensor formula `N_J(X,Y) = [X,Y] + J[JX,Y] + J[X,JY] − [JX,JY]` and the equivalents (`∂̄²=0`, `T^{0,1}` involutive) — all standard.
- **§2 Hermitian metric and Kähler form.** Compatibility `h(JX,JY)=h(X,Y)`, `ω(X,Y)=h(JX,Y)`, antisymmetry, type $(1,1)$, non-degeneracy. The three equivalences for `dω=0` (`∇J=0`; locally `ω = i∂∂̄K`; holonomy ⊂ U(n)) are standard. Examples: `ω = (i/2)Σ dz_j∧d\bar z_j` on `Cⁿ` with potential `½|z|²` ✓ (`i∂∂̄(½|z|²) = (i/2)Σ dz∧d\bar z`); `ω_FS = (i/2π)∂∂̄ log(1+|z|²)` on `CPⁿ` (the `1/2π` normalisation matches `[ω_FS] = c_1(O(1))`); Riemann surfaces always Kähler (every 2-form on a real surface is closed); flat torus `Cⁿ/Λ`; submanifolds/products. Hopf surface `S¹×S³ = (C²\{0})/⟨z↦2z⟩` non-Kähler because `b_2=0`. Verified numerically: `(i/2π)∂∂̄log(1+|z|²) = (i/2π)·dz∧d\bar z/(1+|z|²)²`, density `1/(1+|z|²)²` matches widget readout (modulo the global `1/2π` which the widget honestly labels "scaled").
- **§3 Kähler identities + Hodge.** `[Λ,∂] = i∂̄*` and `[Λ,∂̄] = −i∂*` (standard sign convention, Huybrechts/Griffiths–Harris). Resulting `Δ_d = 2Δ_∂ = 2Δ_∂̄` correct. Hodge decomposition `H^k(M;C) = ⊕_{p+q=k} H^{p,q}` with `H^{p,q} ≅ H^q(M, Ω^p_M)` (Dolbeault). Hodge symmetry `h^{p,q}=h^{q,p}` from real Laplacian + conjugation; Serre duality `h^{p,q}=h^{n-p,n-q}` from Hodge `*`. Diamond-independent count for `n=4`: 9 entries — verified by enumeration `{(p,q): p≤q, p+q≤4}` = 9.
- **§4 Lefschetz.** `L = ω∧−`, `Λ = L*`, `H=[L,Λ]` as the degree-counter, `sl_2` triple. Hard Lefschetz `L^k: H^{n-k} → H^{n+k}` iso for `0≤k≤n`. Primitive `P^{n-k} = ker L^{k+1}`. Lefschetz decomposition `H^m = ⊕_{k≥max(0,m-n)} L^k P^{m-2k}`. All standard. The widget correctly notes Poincaré duality (`H⁰↔H^{2n}`, `b_0=b_{2n}=1`) is the `k=n` case.
- **§5 Calabi–Yau.** `ρ(X,Y) = Ric(JX,Y)`, `[ρ] = 2πc_1(M)` (Chern–Weil). Calabi conjecture statement (Yau 1977/78): every Kähler class on compact Kähler with `c_1=0` contains unique Ricci-flat representative. Monge–Ampère `(ω+i∂∂̄φ)^n = e^f ω^n`. Examples: elliptic curves at `n=1`; K3 (smooth quartic in CP³) at `n=2`, metric non-explicit; quintic threefold with `h^{1,1}=1, h^{2,1}=101, χ=2(h^{1,1}−h^{2,1})=−200` ✓ (Candelas–de la Ossa–Green–Parkes 1991).
- **§6 Kähler–Einstein.** `Ric(ω)=cω` ⇒ `2πc_1(M) = c[ω]`, so `sign c = sign c_1`. Sign chart: Aubin (1976) + Yau (1977/78) for `c_1<0` unconditional; Yau (1977) for `c_1=0`; Chen–Donaldson–Sun (2015) for `c_1>0` iff K-polystable. Matsushima (1957, reductive Aut) and Futaki (1983, vanishing invariant) obstructions. `Bl_1 CP²` (= `F_1`) and `Bl_2 CP²` are Fano with non-reductive automorphism group — no KE. `Ric(ω_FS) = (n+1)ω_FS` on `CP^n` ✓. Yau–Tian–Donaldson statement and K-polystability (test configurations + Donaldson–Futaki invariant) correctly described.

## Wrong / dubious claims (with file:line)

- **kahler-geometry.html:484** — Sentence "Both are local pointwise identities … but they hold globally only because $d\omega = 0$" is misleading. The Kähler identities are *not* pointwise on a general Hermitian manifold; the correct statement is they hold globally *and* their derivation uses `dω=0` essentially. Phrasing as "local pointwise … hold globally" inverts the picture. Minor wording bug, not a math error.
- **kahler-geometry.html:567** — Widget readout: "Top h^{n,0} = h^{0,0} corner is the trivial holomorphic n-form when c_1=0." Wrong: `h^{0,0} = 1` always (constants); `h^{n,0} = 1` *when there is a global holomorphic n-form* (e.g. `c_1=0` for compact Kähler ⇒ trivial canonical bundle ⇒ `h^{n,0}=1`). The two are linked only in the CY case; phrasing as `h^{n,0}=h^{0,0}` is an instance of Serre duality `h^{n,0}=h^{0,n}` plus *Hodge symmetry* `h^{0,n}=h^{n,0}` — the equality with `h^{0,0}` is special to CY. Misstates a general identity. Minor.
- **kahler-geometry.html:386** — "Every Riemann surface ($n=1$): $ω$ is a $2$-form on a real surface, automatically closed" — true for *any* Hermitian metric, but the implicit claim "every Riemann surface is Kähler" requires the surface be *complex* (it is — Riemann surface ≡ 1-dim complex manifold). The statement is correct as is; flagged only because for non-compact / non-paracompact Riemann surfaces some care is needed (every Riemann surface admits a Kähler metric since `H²` of an orientable surface is at most 1-dim). Acceptable.
- **kahler-geometry.html:780** — "the blow-up of $\mathbb{CP}^2$ at one or two points is Fano but admits no Kähler–Einstein metric." Correct, but worth noting for completeness that `Bl_k CP²` for `3≤k≤8` (general points) IS K-polystable Fano with KE metric (Tian 1990). The page omits this contrast — coverage gap, not error.

## Underspecified or unverifiable claims

- **kahler-geometry.html:472** — Widget reports density `1/(1+|z|²)²` without the `1/(2π)` normalisation; the readout calls it "FS density (scaled)" so honest, but the reader must work out which conventional FS the page uses (`(i/2π)∂∂̄log(1+|z|²)`).
- **Coverage gaps relative to user's checklist:**
  - **Kodaira embedding theorem** is not stated anywhere on the page (the user listed it as a focus area). A Kähler manifold whose `[ω]` is a positive integral class is projective.
  - **∂∂̄-lemma** is not stated. The page uses `ω = i∂∂̄K` *locally* but does not state the global ∂∂̄-lemma (a `d`-exact `(p,q)`-form on compact Kähler is `i∂∂̄`-exact). This is a foundational structural result.
  - **Hodge index theorem on surfaces** (signature `(1, h^{1,1}−1)` on `H^{1,1}(X;R)` for compact Kähler surface, or equivalently signature on the Néron–Severi lattice) is not mentioned.
  - **Hodge–Riemann bilinear relations** are named in §4 (line 590) but not stated.
- **kahler-geometry.html:780** — Matsushima's theorem statement on the page is "reductive automorphism group" — strictly Matsushima requires the *identity component* `Aut⁰(X)` to be reductive. Convention; not wrong.
