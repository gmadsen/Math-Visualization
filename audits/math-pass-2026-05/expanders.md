Scope: every mathematical claim in `expanders.html` (1,130 lines, 7 sections + 6 interactive widgets).

## Verified claims (sections)

- **§1 Combinatorial expansion.** $(n,d,\varepsilon)$-expander definition is the standard vertex-expansion form; the restriction $|S| \le n/2$ is correctly justified. Petersen (10v, 3-reg) and $C_{10}$ adjacencies in the widget data are correct; the cycle's $|N(S)|=2$ for any contiguous set is right.
- **§2 Spectral expansion.** Normalized adjacency $\widehat A = A/d$ has spectrum in $[-1,1]$ with $\lambda_1 = 1$ for $d$-regular: correct. Cycle $\lambda_2 = \cos(2\pi/n) \to 1$ correct (eigenvalues are $\cos(2\pi k/n)$). Hypercube $Q_k$ normalized eigenvalue $\lambda_2 = 1 - 2/k$ correct (raw spec $k - 2j$ with multiplicity $\binom{k}{j}$, normalized by $k$). $K_n$ normalized spectrum $\{1, -1/(n-1)^{(n-1)}\}$ correct.
- **§3 Cheeger inequality.** $\phi(G) = \min_{|S|\le n/2} |E(S,\bar S)|/(d|S|)$ is the normalized Cheeger constant. The inequality $\tfrac{1}{2}\lambda_2(\mathcal L) \le \phi(G) \le \sqrt{2\lambda_2(\mathcal L)}$ with $\mathcal L = I - \widehat A$ is the standard Alon–Milman / Dodziuk form. Spectral-sweep proof attribution correct. Dumbbell ($K_5$ + bridge + $K_5$) Cheeger value $\phi \approx 1/(5\cdot 5) = 0.04$ correct: $|E(S,\bar S)|=1$, $d=5$ inside cliques (averages slightly higher with bridge), $|S|=5$. Widget Jacobi solver and symmetric normalized Laplacian $L = I - D^{-1/2}AD^{-1/2}$ are right.
- **§4 Explicit constructions.** Pinsker (1973) random-$d$-regular existence proof correctly attributed. Margulis–Gabber–Galil (1973–81) generators $T_1,\ldots,T_4$ on $(\mathbb Z/n\mathbb Z)^2$ are a standard 8-regular generating set; $SL_3(\mathbb Z)$ property (T) attribution is correct for Margulis's original 1973 argument (Gabber–Galil's 1981 proof avoids (T) via Fourier — the page conflates these slightly but is not wrong about Margulis). LPS (1988): vertex set $\mathrm{PGL}_2(\mathbb F_q) / \mathrm{PSL}_2(\mathbb F_q)$ split by Legendre symbol, $(p+1)$-regular, $|\lambda_{\text{nontriv}}| \le 2\sqrt p = 2\sqrt{d-1}$ — Ramanujan, correct. Zigzag (RVW 2002): $G \boxtimes H$ has $ND$ vertices, degree $d^2$ — correct. Reingold's $\mathrm{SL}=\mathrm L$ application correctly attributed.
- **§5 Applications.** Expander Chernoff / seed-extension for derandomization correctly summarized. Sipser–Spielman (1996) bipartite-expander LDPC sketch (left bits / right parity, low-weight errors fail many checks, linear-time bit-flipping decoder) is correct. Mixing-time formula $O(\log n / \gamma)$ with $\gamma = 1 - \lambda_2$ is the standard reversible-chain bound. Reingold (2004) $\mathrm{SL}=\mathrm L$ via in-place zigzag correctly described.
- **§6 Ramanujan & Alon–Boppana.** Kesten's 1959 spectrum of $T_d$ as $[-2\sqrt{d-1}, 2\sqrt{d-1}]$ correct. Alon–Boppana $\liminf \lambda_2 \ge 2\sqrt{d-1}$ correct. Ramanujan definition correct. ## Wrong / dubious claims (with file:line)

- **`expanders.html:398` — expander mixing constant off by factor 2.** The page asserts $|E(S,\bar S)| \ge \tfrac{d}{2}(1-\lambda_2)\tfrac{|S||\bar S|}{n}$. The standard derivation (Hoory–Linial–Wigderson Lemma 2.4) gives $|E(S,\bar S)| \ge d(1-\lambda_2)\tfrac{|S||\bar S|}{n}$ — **no factor of 1/2**. Tracing the page's own setup: $\frac{2|E(S,S)|}{d} \le \tfrac{|S|^2}{n} + \lambda_2 \tfrac{|S||\bar S|}{n}$, then $|E(S,\bar S)| = d|S| - 2|E(S,S)| \ge d|S||\bar S|/n - d\lambda_2|S||\bar S|/n = d(1-\lambda_2)\tfrac{|S||\bar S|}{n}$. Drop the $\tfrac{1}{2}$.
- **`expanders.html:686` — "Property (T) of $SL_3(\mathbb Z)$" attribution overstated.** Margulis's 1973 expander construction did use property (T) of $SL_3(\mathbb Z)$, but the *generators listed in the page* (the four $T_i$ acting on $(\mathbb Z/n\mathbb Z)^2$) are the **Gabber–Galil 1981** construction whose spectral-gap proof is purely Fourier-analytic and does **not** invoke property (T). The text presents the GG generators alongside a property (T) attribution — these are different proofs of related-but-distinct statements. Either swap to Margulis's $SL_3$ generators (acting on $\mathbb F_p^3$) or drop the property (T) sentence in favor of "elementary Fourier analysis on $(\mathbb Z/n\mathbb Z)^2$".

## Underspecified or unverifiable claims

- **`expanders.html:689` — LPS condition "$p \equiv 1 \pmod 4$" understated.** The full LPS hypothesis is $p, q$ odd primes with $p \ne q$ and (for the Ramanujan property) $q > 2\sqrt p$. The $p \equiv 1\pmod 4$ condition is a clean-pairing convenience used in the original paper (so the integer quaternions of norm $p$ split into $(p+1)$ inverse pairs); LPS-style Ramanujan Cayley graphs exist for $p \equiv 3 \pmod 4$ via Morgenstern's variants. Not wrong, just not the cleanest cite.
- **`expanders.html:692,761` — "spectral gap that is essentially the product of the two parent gaps" + widget's `gap = 0.3 / 1.05^it`.** The actual zigzag bound (RVW Thm 3.2) is $1 - \lambda(G\boxtimes H) \ge (1-\lambda(G))(1-\lambda(H))^2$, not a generic product, and successive squaring keeps the gap bounded below by a constant — it does not slowly decay. The widget's `gap = gap0 / 1.05^it` is decorative/illustrative, not a faithful zigzag estimate (and the schematic is correctly labeled as such, so no prose claim is broken — but a reader inspecting the readout will see a misleading monotone decrease).
- **§4 missing Friedman.** No mention of Friedman's theorem (random $d$-regular graphs are *almost* Ramanujan: $\lambda_2 \le 2\sqrt{d-1} + o(1)$ a.a.s.) — relevant context for §6 since it sharpens Pinsker. Not an error, just a gap.
- **`expanders.html:731` — zigzag widget vertex-count formula `N = seedN^(2^it)`.** A schematic; the actual RVW iteration is $|V(G_{i+1})| = |V(G_i)|^2 \cdot D$ (or $\cdot |H|$), giving $|V(G_i)| \sim |V(G_0)|^{2^i} D^{2^i - 1}$ — close to the widget's formula in spirit. Acceptable for a schematic readout.
