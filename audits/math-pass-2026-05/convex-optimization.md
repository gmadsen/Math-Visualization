## Wrong / dubious claims (with file:line)

- **convex-optimization.html:752, 832** — GW widget readout calls the value of the chosen 5-cycle Gram configuration the "SDP value", but the configuration $v_i$ at angles $0, 72°, 144°, 216°, 288°$ in $\mathbb{R}^2$ (line 762) is **not the SDP optimum** for 5-cycle MAX-CUT. Adjacent inner products are $\cos 72°\approx 0.309$, giving objective $\approx 1.73$, while the integer MAX-CUT on $C_5$ already has value 4 and the true SDP optimum (anti-prism arrangement, adjacent angle $4\pi/5$) is $\approx 4.52$. The "SDP value = 1.73" readout is therefore the value of one feasible Gram point, not the SDP optimum, and the displayed ratio (expected cut / 1.73) overstates the GW guarantee — easy to read as if 1.73 were the LP/SDP relaxation value. Reword to "feasible relaxation value" or use the genuine optimum.
- **convex-optimization.html:855–856** — The displayed Nesterov update uses the textbook coefficient $\tfrac{k-1}{k+2}$, but the inline-code-cell widget (line 873) implements $\beta=k/(k+3)$. Both are valid Nesterov variants, but the prose and the code disagree; either should be made consistent or the divergence flagged in the cell. Math itself is fine in both.

## Underspecified or unverifiable claims

- **§5 line 857** — "Nemirovski–Yudin lower bound for first-order methods on smooth convex problems" — true but only for the black-box first-order oracle model with dimension at least proportional to $k$; not stated, but probably out of scope for the page.
- **§6 line 904** — Newton-decrement quadratic-convergence threshold is given as $\lambda(x)<1/4$. Boyd–Vandenberghe use $\lambda(x)\le \eta$ for some $\eta<\tfrac{1}{4}(3-\sqrt 5)\approx 0.191$ in Algorithm 9.5; $1/4$ is a common upper bound but the exact threshold is variant-dependent. Acceptable as a working number; tighten if you want to be precise.
- **Conjugate table line 281** — `$\mathbb{1}_{[-1,1]}(y)$` uses the LaTeX symbol `\mathbb{1}` for the convex-analytic indicator (0 / $+\infty$). A casual reader may mistake it for the characteristic function (0 / 1). Note in the "norm ↔ indicator of dual-norm ball" cell already disambiguates; consider $\delta_{[-1,1]}$ for clarity.
