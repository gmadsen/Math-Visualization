# cobordism.html — math-correctness audit

## Verified claims

**§1 Equivalence relation / low dims.** Definition of `~` via shared boundary, additive inverse `[M]+[M]=0` from `M⊔M=∂(M×I)`, `Ω_*^O` is graded-commutative `F_2`-algebra, `Ω_0^O=Z/2`, `Ω_1^O=0`, `Ω_2^O=Z/2` generated by `[RP^2]`. Klein bottle bounds the twisted I-bundle over S^1 — all standard and correct. Oriented case `[M]+[\overline M]=0` and Z-algebra structure correct.

**§2 Characteristic numbers.** SW number definition; boundary argument via `TW|_M = TM ⊕ ν` with trivial outward normal — correct. SW numbers are a complete invariant of unoriented bordism (Thom 1954) — correct. SW + Pontryagin numbers complete invariant for `Ω_*^{SO}` — correct (Wall, refining Thom). `w(TRP^n)=(1+a)^{n+1}` and the n=2 calculation `w_1=a, w_2=a^2`, both pairing to 1 — correct. `RP^n` null-cobordant iff n odd — correct.

**§3 Pontryagin–Thom + π_*(MO).** PT construction via tubular neighborhood, collapse to Thom space `T(ν)=D(ν)/S(ν)`, map to `MO(k)=T(γ_k)` — correct. Thom isomorphism `Ω_*^O ≅ π_*(MO)` and reverse via transverse preimage — correct. Generator pattern `F_2[x_i : i ≥ 1, i ≠ 2^k − 1]` — correct (Mersenne degrees excluded).

**§4 Oriented bordism.** `Ω_*^{SO} ≅ π_*(MSO)`. Rational structure `Ω_*^{SO} ⊗ Q ≅ Q[CP^2,CP^4,…]` correct (Thom). Reason `CP^{2k+1}` vanishes rationally (orientation-reversing diffeomorphism via complex conjugation in real dim 4k+2) — correct. Rank in degree 4k = p(k) — correct. Hirzebruch L-class `∏ x_i/tanh x_i`; `L_1=p_1/3`, `L_2=(7p_2−p_1²)/45`, `L_3=(62p_3−13p_1p_2+2p_1³)/945` — all correct. Worked CP^2 example: `p_1(TCP^2)=3x²` and σ=1 — correct.

**§5 Surgery and h-cobordism.** Surgery formula `M' = (M\\int(S^p×D^q)) ∪ D^{p+1}×S^{q-1}` and the trace cobordism via (p+1)-handle attachment — correct. h-cobordism theorem (Smale 1962) with hypotheses simply connected + dim W ≥ 6 — correct. Whitney trick needs ambient dim ≥ 5 — correct. Failure in dim 4 — correct. Wh(Z/5)=Z — correct. s-cobordism with Whitehead torsion τ ∈ Wh(π_1) — correct.

**§6 TQFT.** Cob_d definition with closed (d−1)-mflds as objects, cobordisms with `∂W = \overline{Σ_0} ⊔ Σ_1` as morphisms — correct convention. Atiyah's axioms (symmetric monoidal functor to Vect_k, Z(∅)=k, Z(disjoint)=⊗) — correct. 2D TQFT ↔ commutative Frobenius algebra (Dijkgraaf 1989, Abrams 1996) — correct. Cobordism hypothesis (Baez–Dolan 1995, Lurie 2009): free symmetric monoidal (∞,d)-category on a fully dualizable object, framed bordism — correct statement; tangential structure as homotopy fixed points of O(d)-action — correct.

## Wrong / dubious claims

**cobordism.html:411** — Stated sequence `dim_{F_2} Ω_n^O = 1, 0, 1, 0, 2, 1, 3, 2, 5, 4, 8, 6, 12, …` is wrong from n=7 onward. Correct (partitions into parts ≥2, excluding Mersenne sizes 3,7,15,…): `1, 0, 1, 0, 2, 1, 3, 1, 5, 3, 8, 5, 12, 9, 18`. Page values at n=7,9,11 (2,4,6) should be 1,3,5. The widget readout that uses this list will display incorrect ranks.

**cobordism.html:382** — "Pontryagin's converse" misattributes the full converse (SW numbers determine `Ω_*^O`) to Pontryagin. Pontryagin had partial cobordism results (1947, framed case); the SW-number completeness theorem is Thom 1954. Should read "Thom's converse."

## Underspecified or unverifiable claims

**cobordism.html:411** — Parenthetical "Mersenne dimensions land here" implying `Ω_n^O=0` for Mersenne n is misleading. Vanishing at n=1,3 is incidental (no monomial reaches them); Ω_7^O ≠ 0 (e.g. x_5·x_2). The Mersenne set excludes generator *degrees*, not Ω-vanishing degrees.

**cobordism.html:452** — "topological index of d+d* on even forms" is a loose paraphrase of the signature operator (acts between self-dual / anti-self-dual forms via the ±1 eigenspaces of the Hodge star). Not wrong, just imprecise; experts will read past it.

**cobordism.html:511** — "Donaldson and Freedman gave examples" is loose attribution. The smooth h-cobordism failure in dim 4 is conventionally credited to Donaldson (gauge theory invariants distinguishing h-cobordant 4-manifolds); Freedman's role is the topological h-cobordism in dim 4. Wording overstates Freedman's part in producing counterexamples.

**cobordism.html:515** — "Newman 1966" for topological Poincaré in dim ≥5 is a defensible but partial attribution; the full topological case for n ≥ 5 also depends on Kirby–Siebenmann (1969). Acceptable for a survey.

Everything substantive — definitions, ring structures, Thom calculation pattern, signature theorem, h-cobordism statement, cobordism hypothesis — checks out.
