## §7 Convergence theorems (lines 936–1101)

  - **DCT:** $f_n\to f$ a.e., $|f_n|\le g$ a.e. with $g\in L^1$ ⇒ $f\in L^1$, $\int f_n\to\int f$, $\int|f_n-f|\to 0$. Proof via Fatou applied to $g\pm f_n$. Correct.

## §10 Fubini & Tonelli (lines 1352–1474)

- **Verified.**
  - **Tonelli** (σ-finite, $f\colon X\times Y\to[0,\infty]$ measurable): all three integrals (double + two iterated) exist in $[0,\infty]$ and agree. No integrability hypothesis. Correct standard statement.
  - **Fubini:** $f\colon X\times Y\to\mathbb{C}$ with $\int|f|<\infty$ ⇒ iterated integrals exist for a.e. section, are equal, agree with double. Correct.
  - **Discrete telescoping counterexample (lines 1365–1367):** $a_{m,n} = 1$ if $n=m$, $-1$ if $n=m+1$, else 0 (with $m,n\ge 0$). Row sums (over $n$) $\equiv 0$, so iterated $\sum_m\sum_n = 0$. Column sums: for $n=0$, only $a_{0,0}=1$ contributes (the term $a_{m,0}=-1$ would require $m+1=0$, impossible); for $n\ge 1$, $a_{n,n}+a_{n-1,n} = 1-1 = 0$. So iterated $\sum_n\sum_m = 1$. Disagreement because $\sum|a_{m,n}|=\infty$. Correct.
  - Fubini layer-cake proof (line 1361): indicators of rectangles → simple → nonneg measurable (Tonelli) → $L^1$ split $f^\pm$. Correct standard arc.
  - **Operational protocol (line 1373):** "compute $\int\int|f|$ first via Tonelli; if finite, $f\in L^1(\mu\otimes\nu)$, Fubini swap is licensed." Correct.
  - Fubini widget: region $R_\alpha = \{x,y\ge 0, x^\alpha+y^\alpha\le 1\}$, area via numerical iteration in either order. Both orders agree (Tonelli on the indicator of a measurable set). Correct.

- **Wrong/dubious.**
  - **Continuous Fubini-failure example (lines 1369–1371) — sign error.** The page asserts:
    > on $[0,1]^2$, $f(x,y) = (x^2-y^2)/(x^2+y^2)^2$, then $\int_0^1\!\int_0^1 f\,dx\,dy = \pi/4$ while $\int_0^1\!\int_0^1 f\,dy\,dx = -\pi/4$.
    Direct computation: $\partial/\partial x[x/(x^2+y^2)] = (y^2-x^2)/(x^2+y^2)^2 = -f$, so $\int_0^1 f(x,y)\,dx = -[x/(x^2+y^2)]_0^1 = -1/(1+y^2)$, then the outer integral $\int_0^1 -1/(1+y^2)\,dy = -\pi/4$. With the standard "right-to-left" reading where $dx\,dy$ means inner $dx$ (then outer $dy$), the value is $-\pi/4$, not $+\pi/4$. By antisymmetry under $(x,y)\mapsto(y,x)$, the other order gives $+\pi/4$, not $-\pi/4$. The two assigned values are **swapped**. The conclusion (iterated integrals disagree, witnessing Fubini failure) is correct, but the two stated signs should be exchanged.

- **Underspecified.** Convention for which differential is "inner" in $\int\int f\,dx\,dy$ is not declared in the prose; the dispute over the signs above turns on this. The standard mathematical convention is right-to-left, but some applied-math sources read left-to-right; if the page were using left-to-right then the values match — but then the §9 σ-finiteness counterexample is also wrong by the same convention. Cross-checking §9 confirms the page does use right-to-left (the §9 example matches the right-to-left reading), so §10 is internally inconsistent.
- **Severity.** **Minor.** Sign typo in a famous worked example. Result table looks mathematically wrong by the page's own convention.
