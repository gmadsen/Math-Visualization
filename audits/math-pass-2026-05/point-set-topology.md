Basis conditions (covering + intersection refinement) and subbasis-as-finite-intersection — correct. - **§3 Continuity / homeomorphism.** Preimage-of-open definition, equivalence with $\varepsilon$–$\delta$ on metric spaces, composition behavior, homeomorphism = continuous bijection with continuous inverse. Identity $(\mathbb R,\tau_{\mathrm{disc}})\to(\mathbb R,\tau_{\mathrm{usual}})$ continuous but inverse not — correct. Cut-point obstruction for $(0,1)\not\cong S^1$ — correct. $[0,1]\not\cong(0,1)$ via compactness or non-cut-point count — correct. "Continuous image of connected is connected; of compact is compact" — correct.
- **§4 Compactness.** Open-cover definition, FIP equivalent, Heine–Borel in $\mathbb R^n$, EVT, uniform continuity on compact metric domains, "compact→Hausdorff continuous = closed → bijective ⇒ homeo," Tychonoff product theorem $\Leftrightarrow$ AC (Kelley 1950) — all correct. $\ell^2$ unit ball non-compact via $\|e_i-e_j\|=\sqrt2$ — correct. Sequential ↔ open-cover compactness coincides on metric spaces, diverges in general — correct.
- **§5 Connectedness.** Definition, clopen characterization, examples ($\mathbb R^n$, $\mathsf{GL}_n(\mathbb C)$ connected vs $\mathsf{GL}_n(\mathbb R)$ two components by $\mathrm{sgn}\det$, $\mathbb Q$ disconnected via $\sqrt2$ cut). Path-connected ⇒ connected (pull back the separation along the path). Topologist's sine curve $T=\{(x,\sin(1/x)):x\in(0,1]\}\cup\{0\}\times[-1,1]$ — connected (closure of connected) but not path-connected, with path components = (segment, graph). Components closed; path components partition and refine the connected partition; path components can fail closed (sine-curve graph piece) — correct. IVT as connected-image + intervals-are-connected-subsets-of-$\mathbb R$ — correct.
- **§6 Separation & countability.** $T_0$–$T_4$ ladder with $T_3,T_4$ implicitly bundling $T_1$. Implications $T_4\Rightarrow T_3\Rightarrow T_2\Rightarrow T_1\Rightarrow T_0$, every metric is normal, compact Hausdorff is normal, Urysohn lemma (normal $\Rightarrow$ disjoint closeds separated by $f:X\to[0,1]$), Urysohn metrization (regular + 2nd-countable + Hausdorff ⇒ metrizable) — all correct. Counterexample table (indiscrete, Sierpiński, cofinite $\mathbb Z$, Euclidean $\mathbb R$, double-origin line, Niemytzki/Moore plane) — every $T_i$ pass/fail and every "why" string is correct, including Niemytzki failing $T_4$ via Jones' lemma (separable + closed-discrete subspace of cardinality $\mathfrak c$).

## Wrong / dubious claims

- **`point-set-topology.html:1130`** — "sequences can have at most one limit **iff** the space is Hausdorff." The "iff" is wrong in general: Hausdorff ⇒ unique sequence limits always, but the converse needs first-countability. Standard counterexample: an uncountable set with the cocountable topology — every convergent sequence is eventually constant (so limits unique) yet the space is not Hausdorff. Fix: either restrict to first-countable / metrizable, or replace "iff" with "in" (Hausdorff ⇒ unique limits, and conversely on first-countable spaces).
- **`point-set-topology.html:822`** — "every net (or **filter**) has a convergent subnet." Filters don't have "subnets"; the filter formulation is "every ultrafilter converges" (equivalently, every filter has a cluster point / a finer convergent filter). The net version is correct. Suggested fix: drop "(or filter)" or rewrite as "every net has a convergent subnet; equivalently every ultrafilter converges."

## Underspecified or unverifiable claims

- **`point-set-topology.html:1009`** — "any finite space with the discrete topology" is disconnected. Trivially false for the 1-point case (which is connected). Pedantic but worth tightening to "any finite discrete space with $\ge 2$ points."
- **`point-set-topology.html:1070`** (widget readout) — the verdict for tangent disks ("any separation $U\sqcup V$ would have to assign the touching point to one side; neither $U$ nor $V$ is then open") is hand-wavy. Cleaner argument: each disk is connected, so each must lie wholly inside $U$ or wholly inside $V$; the shared touching point forces both into the same side, so the other side is empty. The current phrasing isn't wrong but is hard to parse.
- **`point-set-topology.html:1135`** — "regular, second-countable Hausdorff" — under the page's own $T_3$-includes-$T_1$ convention, "regular" already implies Hausdorff, so this is mildly redundant (matches the most common textbook phrasing, though).
