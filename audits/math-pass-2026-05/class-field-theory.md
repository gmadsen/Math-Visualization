# Math-correctness audit — `class-field-theory.html`

## Verified claims (sections)

- **§1 Motivation.** Cyclotomic Galois group `Gal(Q(ζ_n)/Q) ≅ (Z/n)^×`, σ_a(ζ_n)=ζ_n^a, Frobenius for unramified p is σ_p, and Kronecker–Weber `Q^ab = ⋃_n Q(ζ_n)` — all standard and stated correctly.
- **§2 Class group.** Definition of fractional ideals, Cl(K) = I_K/P_K, h_K=1 ⇔ PID. Worked example Q(√-5): p=(2,1+√-5), p²=(2) verified by direct computation. Heegner-Stark list of nine d with h=1 (-1,-2,-3,-7,-11,-19,-43,-67,-163) is the canonical complete list.
- **§2 widget table.** Spot-checked: h(-14)=4, h(-23)=3, h(-47)=5, h(-71)=7, h(-89)=12, h(-79)=5 — all correct against Cohen tables.
- **§3 Hilbert class field.** Furtwängler/Artin theorem statement (unique unramified abelian extension, [H:K]=h_K, Cl(K) ≅ Gal(H/K)) and principal ideal theorem stated correctly.
- **§3 worked examples.** HCF(Q(√-5)) = Q(√-5,i) = Q(√-1,√5) ✓ (genus field; disc=-20, ramified primes 2,5 unchanged). HCF(Q(√-6)) = Q(√-6,√-3) = Q(√2,√-3) ✓. HCF(Q(√-23)) = K(α), α³-α-1=0 ✓ (disc(x³-x-1)=-23). HCF(Q(√-15)) = Q(√-3,√5) ✓. Genus field of Q(√-14) = Q(√-14,√2) ✓.
- **§4 Artin map.** Frobenius definition, multiplicative extension to I_K^S, conductor-form reciprocity (factors through Cl_m, kernel generated by completely-split primes) — correct.
- **§4 Q(√-5) Artin widget.** Inert case (Legendre(-5,p)=-1): Frob acts on i by x↦x^{p²}=i since p odd, so Frob=id, P principal — correct. Split case: principal iff p ≡ 1, 9 (mod 20) (representable by x²+5y²) vs non-principal iff p ≡ 3, 7 (mod 20) (representable by 2x²+2xy+3y²) — classical Cox/Gauss result, correct.
- **§5 Ray class group.** Definition of modulus, I_K^m, P_K^m, Cl_m(K). For K=Q, m=n·∞, Cl_m(Q) = (Z/n)^× — correct.
- **§5 Idèles.** Restricted product definition, idèle-class group C_K = A_K^×/K^×, idelic Artin map θ_K with kernel = connected component of 1, bijection with finite-index open subgroups — all standard.
- **§6 Takagi existence.** Bijection between abelian extensions and admissible congruence subgroups (classical) and finite-index open subgroups of C_K (idelic), with anti-isomorphism of lattices — correct.
- **§7 Conductor-discriminant.** d_{L/K} = ∏_χ f(χ) over characters of Gal(L/K) — correct (Hasse Führerdiskriminantenproduktformel).
- **§8 Quadratic reciprocity.** q* = (-1)^{(q-1)/2}q, Q(√q*) is the unique quadratic subfield of Q(ζ_q), Frob_p = id ⇔ p splits ⇔ (q*/p)=+1, deduce (q*/p)=(p/q) — argument is correct.
- **§9 Langlands dictionary.** Abelian = CFT (proved 1930s); non-abelian = Langlands; GL_n over function fields proved (Drinfeld n=2, L./V. Lafforgue); Artin↔Hecke L-functions for GL_1 — correctly stated.

## Wrong / dubious claims (with file:line)

- **`class-field-theory.html:1011`** — The "specialising" cyclotomic disc formula is mathematically broken: `p^{φ(n)(1-1/(p-1))/⋯}` contains a literal trailing `/⋯` and the exponent itself is not the standard form. The textbook formula is `disc(Q(ζ_n)) = (-1)^{φ(n)/2} n^{φ(n)} / ∏_{p|n} p^{φ(n)/(p-1)}`. As displayed it is not a real formula.
- **`class-field-theory.html:907`** — "Hilbert class field (all-ramified = O_K^× kernel)" is a confusing/incorrect parenthetical. The HCF corresponds to the closed subgroup K^× · ∏_v O_v^× · (∏_{v|∞} K_v^{×,0}) inside the idèles, modulo K^× — not "O_K^×". O_K^× sits inside K^× already; the actual kernel is the image of the unit-idèle subgroup ∏_v O_v^× in C_K. As written it conflates the global units with the unit-idèle subgroup.
- **`class-field-theory.html:751`, `:771`, `:910`, `:918`** — "For Q(ζ_n)/Q the conductor is n·∞" is true only when n ≢ 2 (mod 4). When n ≡ 2 (mod 4), Q(ζ_n) = Q(ζ_{n/2}) and the conductor is (n/2)·∞. Several places assert n·∞ unconditionally.

## Underspecified or unverifiable claims

- **`:888`** "There is a unique abelian extension K(m)/K — the ray class field of conductor m — with Gal ≅ Cl_m(K)." Slightly imprecise: K(m) is the maximal abelian extension of K with conductor *dividing* m; calling m "the conductor" is reserved for the minimal such m. The next sentence does call out the minimal modulus, but the leading sentence reads as if every m is a conductor.
- **`:984`** Existence theorem (classical form) requires "admissible" congruence subgroups (containing P_K^m) — the page does include the inclusion `P_K^m ⊆ H ⊆ I_K^m`, which is the admissibility condition, so this is fine; just worth noting that "of finite index" + the inclusion is equivalent to "open" in the idelic picture.
- **Local class field theory** — listed in the focus areas but the page does not state local CFT (local Artin map K_v^× → Gal(K_v^ab/K_v), local existence theorem). Mentioned only in passing via the widget id `local-global-cft`. Absent, not wrong.
- **Class field tower / Golod–Shafarevich** — listed in focus areas but not present. The §3 widget is titled "Hilbert class field tower" but only displays the single step H/K/Q, not an iterated tower. Absent, not wrong.

## Severity

**Minor.** No false theorem statements. The single broken formula at line 1011 is a display typo (`/⋯` placeholder) that should be deleted or fixed. The "O_K^× kernel" parenthetical at line 907 is misleading and should be rephrased to "unit idèles ∏_v O_v^×". The "n·∞" conductor claims should be qualified for n ≡ 2 (mod 4). All worked examples (Q(√-5), Q(√-6), Q(√-14), Q(√-15), Q(√-23), Heegner list, ideal-form representability) are arithmetically correct.
