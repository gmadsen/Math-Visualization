## Wrong / dubious claims

### Major

- **§1 Hilbert-90 widget — wrong sign convention in the trivialisation** (lines 295, 585, 591). The page text says "Take $\alpha = 1 + \beta$ (when nonzero); the readout displays the witness and verifies the trivialisation." The widget code constructs $\alpha = c \cdot (1 + \beta) = (c+a) + bi$ and then verifies $\sigma(\alpha)/\alpha = \beta$ against the input. But the Speiser construction with $\alpha = 1 + \beta$ gives

  $$\sigma(\alpha)/\alpha \;=\; \frac{1+\sigma(\beta)}{1+\beta} \;=\; \frac{1+\beta^{-1}}{1+\beta} \;=\; \frac{1}{\beta},$$

  not $\beta$ (using $N(\beta) = 1 \Rightarrow \sigma(\beta) = 1/\beta$). For example, $\beta = (3+4i)/5$: $\alpha = 5(1+\beta) = 8 + 4i$, $\sigma(\alpha) = 8 - 4i$, $\sigma(\alpha)/\alpha = (8-4i)/(8+4i) = (3-4i)/5 = \sigma(\beta) = 1/\beta$. The verification at line 591 (`numIm/denom - b/c`) demands the imaginary part match $b/c$, but it actually equals $-b/c$, so the assertion that "matches beta" is structurally false for any input with $b \ne 0$ — the widget should display "mismatch" for every cocycle test in its dropdown except $\beta = -1$.

  The correct fix is one of:
  - Change the formula to $\alpha = 1/(1+\beta)$ — i.e. $\alpha = c/((c+a) + bi) = c \cdot ((c+a) - bi)/((c+a)^2 + b^2)$. Then $\sigma(\alpha)/\alpha = \beta$.
  - Or keep $\alpha = 1+\beta$ but advertise the trivialisation as $\alpha/\sigma(\alpha) = \beta$ (equivalently switch the cocycle convention to $\varphi(g) = \alpha / g(\alpha)$). The Hilbert-90 statement is identical under either convention.

  This is a substantive error in the worked computation. The pedagogical claim ("every norm-one element is a coboundary") is right, but the witness formula is off by inversion.

  (Caveat: I have not run the widget — analysis above is from reading the source. A live test would confirm whether the readout actually prints "mismatch" or whether some sign reshuffling elsewhere masks the error. Either way, the displayed witness $\alpha = c(1+\beta)$ does not satisfy $\sigma(\alpha)/\alpha = \beta$.)

### Minor

- **§3 widget cocycle for $Q_8 \to V_4$** (line 677). Reads "$c(i, j) = -1, c(i, i) = -1, \dots$ (representative 2-cocycle)." With the natural section $s(\bar i) = i, s(\bar j) = j, s(\bar k) = k$ in $Q_8$, one computes $s(\bar i) s(\bar j) = ij = k = s(\bar k)$, so $c(\bar i, \bar j) = +1$, not $-1$. (The non-trivial sign appears at $c(\bar j, \bar i) = -1$ since $ji = -k$, and at $c(\bar i, \bar i) = -1$ since $i^2 = -1$.) Different choices of section produce cohomologous but distinct cocycles, so the displayed $-1$ is a representative of the same non-trivial class as the standard one — the qualitative point (Schur cover, non-trivial in $H^2$) is right. Sign of the off-diagonal value is a section-dependent convention but the page asserts it as a single "the cocycle" without stating the section.

- **§3 Heisenberg cocycle "alternating bilinear"** (line 691). The cocycle $c((a_1, b_1), (a_2, b_2)) = a_1 b_2$ is bilinear but **not** alternating ($c((a,b), (a,b)) = ab \ne 0$ in general). Its cohomology class is detected by the antisymmetrisation $(a_1 b_2 - a_2 b_1)/2$, which IS alternating bilinear and generates the symplectic-form line in $H^2((\mathbb{Z}/p)^2, \mathbb{Z}/p)$. Calling the cocycle itself "alternating bilinear" is a slip; the *class* is.

- **§2 widget readout for the trivial torsor** (line 631). "Galois sigma swaps sheets pointwise, but each sheet is itself a copy of Spec Q." For the trivial torsor $\mathrm{Spec}(\mathbb{Q}[t]/(t^2 - 1)) = \mathrm{Spec}(\mathbb{Q}) \sqcup \mathrm{Spec}(\mathbb{Q})$, $\sigma \in \mathrm{Gal}(\bar{\mathbb{Q}}/\mathbb{Q})$ acts trivially on both sheets — there is no swap. The "swap" is the action of $\mu_2$ as the structure group of the torsor (which permutes the two sheets), not the Galois action. The readout conflates the two. The non-trivial-torsor readout ("Galois sigma swaps the two sheets globally") is correct.

- **§4 Brauer widget over $\mathbb{Q}_3, \mathbb{Q}_5$** (lines 779–781). The readout label `inv_${p} (a,b)_2` correctly displays the local invariant in $\mathrm{Br}(\mathbb{Q}_p)$. The follow-up sentence says the algebra "is the local quaternion division algebra at $p = ${p}$" when the invariant is $1/2$. This is right (over a local field, the unique non-trivial 2-torsion Brauer class is the quaternion algebra), but the JS allows arbitrary integer $a, b$ inputs without normalising them mod $(\mathbb{Q}_p^\times)^2$ — for instance, entering $a = 4, b = 9$ would give the same answer as $a = 1, b = 1$ since these are squares, but the JS computes the symbol from the raw values, returning $0$ correctly because the formula handles it. Verified: for $a$ a unit square (e.g. $a=1$, $\alpha = 0$, $u_a = 1$), `term = legendre(1,p)^β · legendre(u_b,p)^0 = 1 · 1 = 1`, so the symbol is 0. Fine.

- **§4 Kummer/cyclic-algebra hint** (line 429). "$H^2(K, \mu_n \otimes \mu_n) \cong H^2(K, \mu_n)$" — the iso $\mu_n \otimes \mu_n \cong \mu_n$ uses the chosen primitive $n$-th root of unity (it is canonical only after that choice). Page does not flag the choice. Minor.

- **§6 "rank determined by Selmer modulo III[n]"** (line 551). Slight imprecision: more accurately, $\mathrm{rk}(E(K)) = \log_n |\mathrm{Sel}_n| - \log_n |\mathrm{III}[n]| - \log_n |E(K)[n]|$ — the $n$-torsion of $E(K)$ also contributes. The phrasing is fine as a heuristic but not a clean formula.

- **§4 widget sentence "The Hilbert symbol $(a,b)_p$ takes values in $\{0, 1/2\} \subset \mathbb{Q}/\mathbb{Z}$"** (line 452). Correct; just note that this is the additive-in-$\mathbb{Q}/\mathbb{Z}$ presentation (multiplicative in $\mu_2 = \{\pm 1\}$, the two are isomorphic via $\pm 1 \leftrightarrow 0, 1/2$).

- **Widget §1 readout uses ASCII transliterations of LaTeX** (`varphi`, `sigma`, `alpha`, `beta`, `^`) instead of the KaTeX text in the surrounding HTML. Stylistic inconsistency, not a math error — but combined with the sign bug above, it makes the readout extra hard to cross-check.

## Underspecified or unverifiable claims

- **§1 Kummer SES caveat "(when $\mathrm{char}(K) \nmid n$ and $\mu_n \subset K$)"** (line 298). The SES $1 \to \mu_n \to \bar K^\times \xrightarrow{n} \bar K^\times \to 1$ requires only $\mathrm{char}(K) \nmid n$; the LES identification $H^1(K, \mu_n) = K^\times/(K^\times)^n$ also holds without $\mu_n \subset K$. The condition $\mu_n \subset K$ is needed if you want to further identify $H^1(K, \mu_n) = \Hom(G_K, \mathbb{Z}/n)$ (i.e., to forget the Galois twist on $\mu_n$). The page's parenthetical conflates the two conditions.

- **§4 cyclic algebra uses the assumption "$\mu_n \subset K$"** (line 427) — required for the relation $yx = \zeta_n xy$ to make sense over $K$. Correctly stated.

- **§5 dual module $M^*$ for $M$ a finite Galois module** (line 475). The page writes $M^* = \Hom(M, \bar K^\times)$; for $M$ finite of order $n$, $\Hom(M, \bar K^\times) = \Hom(M, \mu_n)$ as Galois modules. The page does not spell this out, leaving the reader to wonder why a non-cyclic $M$ pairs into the abelian group $\bar K^\times$. Minor pedagogy.

- **§4 "Br$(\mathbb{Q}_p) = \mathbb{Q}/\mathbb{Z}$ (the local invariant of CFT)"** (line 455). The local invariant is a canonical isomorphism (after choosing the Frobenius-direction convention for unramified extensions). Correct, as standardly stated.

- **§5 quiz Q3 explanation** ("the unramified Brauer group is $\mathrm{Br}(K^{\mathrm{ur}}/K) = \mathbb{Q}/\mathbb{Z}$ via Frobenius, and this exhausts $\mathrm{Br}(K)$"). Correct in spirit: $\mathrm{Br}(K) = \bigcup_n \mathrm{Br}(L_n/K)$ where $L_n$ is the unramified degree-$n$ extension, and this filtered union is $\mathbb{Q}/\mathbb{Z}$. Standard local-CFT computation.

## Severity

**minor errors with one major**.

The §1 Hilbert-90 widget's trivialisation formula is wrong by inversion: $\alpha = 1+\beta$ gives $\sigma(\alpha)/\alpha = 1/\beta$, not $\beta$. The verification check in the JS therefore should fail on the displayed dropdown options (except for $\beta = -1$, which is self-inverse). This is the worked example for the page's banner result (Hilbert 90), so the bug is high-visibility. Recommend fix: change to $\alpha = 1/(1+\beta)$ in both the prose and the JS, or rephrase the cocycle convention to $\beta = \alpha/\sigma(\alpha)$ (equivalent statement of Hilbert 90, just with the opposite sign).

The §3 widget's $Q_8 \to V_4$ cocycle has $c(i,j) = -1$ rather than the standard-section value $+1$ — this is a section-convention quibble, not a math error, since both representatives are in the same non-trivial class of $H^2(V_4, \mathbb{Z}/2) = \mathbb{Z}/2$.

The §3 widget's "alternating bilinear" Heisenberg cocycle is bilinear but not alternating; its class is alternating after antisymmetrisation. Wording slip.

The §2 trivial-torsor readout confuses $\mu_2$-action (which swaps sheets) with the Galois action (which is trivial on the trivial torsor). Wording slip.
