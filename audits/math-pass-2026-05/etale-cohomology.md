# Math-correctness audit — etale-cohomology.html

- **§1 Étale morphisms.** Decomposition flat + unramified + lfp = étale, Jacobian-criterion form `B = A[t]/(g)` with `det(∂g/∂t)` a unit, Frobenius `t↦t^p` failing étale because `dF = pt^{p-1} = 0` in char `p`, Kummer cover `t↦t^n` on `G_m` étale iff `gcd(n,p)=1` with Galois group `μ_n` — all correct. Étale-site definition (jointly-surjective covers), `π_1^ét(Spec k) = Gal(k̄/k)`, and `π_1^ét(X) =` profinite completion of `π_1^top(X(C))` for smooth proj `/C` — all correct.
- **§2 ℓ-adic cohomology.** Definition `H^i_ét(X, Q_ℓ) := (lim H^i_ét(X, Z/ℓ^n)) ⊗ Q_ℓ` with `ℓ ≠ p` — correct. Comparison theorem (Artin) `H^i_ét(X, Q_ℓ) ≅ H^i_sing(X(C), Q) ⊗ Q_ℓ` for smooth projective `X/C` — correct. Smooth surface degree `d` in `P³`: `b_2 = d³−4d²+6d−2`, `h^{2,0}=(d−1)(d−2)(d−3)/6` — correct (verified for `d=3` cubic ⇒ `b_2=7`, `χ=9`; `d=4` quartic K3 ⇒ `b_2=22`). Curve `b=(1,2g,1)`, `P^n` `b=(1,0,1,…,0,1)`, `E×E` Künneth `(1,4,6,4,1)`, `χ(E×E)=0` — correct. `b_{2i}≥1` from hyperplane class — correct.
- **§3 Lefschetz fixed-point formula.** Classical and étale statements `#Fix(f) = Σ(−1)^i Tr(f* | H^i)` — correct. Frobenius transversality argument: at fixed point, `T(Δ) = {(v,v)}` and `T(Γ_F) = {(v,0)}` since `dF = 0`, sum is direct and spans — correct. `H*(P^n)`: `H^{2i}` 1-dim with `Frob_q` acting as `q^i`, all odd vanish; trace `Σq^{im} = (q^{m(n+1)}−1)/(q^m−1) = #P^n(F_{q^m})` — correct. Curve formula `#X(F_{q^m}) = 1 + q^m − Σ(α_j^m + ᾱ_j^m)` and Weil bound `|#X(F_q) − (q+1)| ≤ 2g√q` — correct. Power-sum recurrence `p_m = a·p_{m-1} − q·p_{m-2}`, `p_0=2`, `p_1=a` — correct.
- **§4 Weil conjectures.** Zeta-function definition, Lefschetz factorization `Z(X,t) = Π det(1 − t·Frob | H^i)^{(−1)^{i+1}}`, W1 rationality with deg-`b_i` integer factors, W2 functional equation `Z(1/(q^d t)) = ±q^{dχ/2} t^χ Z(t)`, W3 Riemann hypothesis `|ι(α)| = q^{i/2}` — all correctly stated. Genus-1 numerator `L(t) = 1 − a_q t + q t²`, `α + β = a_q`, `αβ = q`, Hasse `|a_q| ≤ 2√q` — correct. Sato–Tate density `(2/π) sin²θ dθ` on `[0,π]` for non-CM elliptic curves — correct (curve `y²=x³−x+1` is non-CM; `j = −6912/23`).
- **§5 Comparison theorems.** Artin's `Z/ℓ^n` and `Q_ℓ` comparisons, Grothendieck de Rham `H^i_dR(X/C) ≅ H^i_sing(X(C), C)`, crystalline cohomology over `W(k)` with semi-linear Frobenius, p-adic Hodge isomorphism `H^i_ét(X_K̄, Q_p) ⊗ B_cris ≅ H^i_cris(X_k/W) ⊗ B_cris` — all correctly stated. Period rings `B_dR, B_cris, B_st` named appropriately.

## Wrong / dubious claims (with file:line)

- **etale-cohomology.html:707, 723 — wrong `a_q` for the third elliptic curve option.** Dropdown labels and stored data say *"`y² = x³ + x + 1` over `F_5` (`a_q = −2`)"*. Direct enumeration: `#E(F_5) = 9`, so `a_5 = 5+1−9 = −3`, not `−2`. The curve with `a_5 = −2` is `y² = x³ − x + 1` (`#E=8`). Either the equation has a sign typo or the eigenvalue does. The widget's drawn `(α,β)` then corresponds to a phantom curve, not the labelled one. Math-correctness bug.
- **etale-cohomology.html:864 — supersingular characterization wrong.** Widget caption: *"arcs collapse to the real axis at the endpoints (supersingular splits in char p)"*. The endpoints `a_q = ±2√q` correspond to coincident real eigenvalues, but supersingular elliptic curves are characterized (over `F_p`, `p≥5`) by `a_p ≡ 0 mod p`, typically `a_p = 0`, i.e. the *middle* of the Hasse interval, not the endpoints. The endpoint case forces `α = β = ±√q ∈ Z`, which only happens for non-prime `q` (since `√q` must be an integer); supersingular ≠ endpoint.
- **etale-cohomology.html:869 — discriminant comment wrong.** Code comment: *"bad reduction for `y² = x³ − x + 1` (`Δ = −16·(4(−1)³+27)= −16·23 ≠ 0 actually`); keep simple: skip 31 just in case"*. Two issues: (a) the formula gives `Δ = −16·23 = −368`, so the curve has bad reduction at the prime divisors of `−368 = −2⁴·23`, namely `2` and `23` — not `31`; (b) the comment skips `p=31` for no actual reason. Skipping is harmless cosmetically (Sato–Tate uses many primes), but the math comment is incorrect.

## Underspecified or unverifiable claims

- **K3 widget §3 (line 588–594, 652).** Schematic option `'k3'` sets `tr2 = 22 q^m` (all 22 H² eigenvalues equal to `+q`). The caption admits this is "stylised supersingular limit". A genuine supersingular K3 has all eigenvalues being roots of unity times `q`, with sum bounded in `[−22q, +22q]`; the upper-bound case `+22q` is the trivial Frobenius, not the standard supersingular setup. Honestly labeled as schematic, so not wrong, but "supersingular limit" is loose terminology.
- **Curve schematic data (`g2`, `g3`).** Pairs `(2, −1)` for `g=2` and `(1, 2, −1)` for `g=3` are plausible Hasse-bound-respecting integer traces but are not tied to any specific curve. Self-consistent within Weil bounds but unverifiable as a real-curve claim.
- **6-functor formalism / constructible sheaves.** The audit prompt requested coverage of these; the page does not address either. Absent rather than wrong.
- **Comparison theorem hypothesis (§2 line 349).** Stated for "smooth projective variety over `C`". Artin's theorem holds in greater generality (smooth or even arbitrary varieties of finite type with appropriate finiteness hypotheses for the `Z/n` form, proper for the unrestricted `Q_ℓ` form). Restriction is conservative, not wrong.

All five sections' core mathematics — étale criteria, ℓ-adic definition, comparison theorems, Lefschetz formula, Weil conjectures W1/W2/W3, Sato–Tate density — is correct.
