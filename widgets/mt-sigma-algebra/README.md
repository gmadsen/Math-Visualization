# mt-sigma-algebra

Bespoke module for **measure-theory** §2 (σ-algebras and measures). Builds the
σ-algebra generated by a family of subsets and makes the atom description
tangible.

See [../README.md](../README.md) for the registry contract (schema + pure
render functions) and the bespoke-vs-shared distinction.

## What it does

On $X=\{1,2,3,4\}$, toggle generators from a bank into the family
$\mathcal{E}$. The widget computes the **atoms** — the partition of $X$ where
two points lie together iff every generator contains both or neither — colours
$X$ by atom, and lists every element of $\sigma(\mathcal{E})$, which is exactly
the set of unions of atoms. Hence $|\sigma(\mathcal{E})|=2^{\#\text{atoms}}$. It
confirms the three axioms ($\varnothing\in\mathcal{A}$, closed under complement,
closed under union) on the result. Presets sweep from the trivial
$\{\varnothing,X\}$ (one atom) through a single event and a partition to the
discrete $2^X$ (every singleton an atom). The same construction applied to the
open sets of $\mathbb{R}$ gives the Borel σ-algebra.

## Params

See [`schema.json`](./schema.json) for the authoritative shape.

| field | type | purpose |
|---|---|---|
| `widgetId` | string | DOM id for the outer `<div class="widget">` wrapper. |
| `title`    | string | Display title (prose — `.ttl` is uppercased). |
| `hint`     | string (optional) | Short hint rendered next to the title. |

## Usage

```json
{ "type": "widget", "slug": "mt-sigma-algebra", "params": { "widgetId": "w-mt-sigma", "title": "Building the σ-algebra generated by a family" } },
{ "type": "widget-script", "ref": "w-mt-sigma" }
```

Then `node scripts/rebuild.mjs --only widget-params` to AJV-validate, and
`node scripts/rebuild.mjs` for the full byte-identical round-trip gate.
