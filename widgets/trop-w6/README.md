# `trop-w6`

Mikhalkin correspondence counter for `tropical-geometry` §6. Slide the degree $d$ from $1$ to $4$; the widget displays the number $3d-1$ of generic points required, the matching tropical curve count $N_d^{\mathrm{trop}}$, and confirms agreement with the Gromov–Witten invariant of $\mathbb{P}^2$.
