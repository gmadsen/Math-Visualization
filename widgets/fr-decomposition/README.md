# fr-decomposition

Bespoke module for **frobenius-and-reciprocity** §5 (Decomposition and inertia
groups). Shows the local Galois group at a prime, the inertia subgroup, and
where Frobenius lives.

See [../README.md](../README.md) for the registry contract (schema + pure
render functions) and the bespoke-vs-shared distinction.

## What it does

Steppers set the ramification index $e$, residue degree $f$, and number of
primes $r$ above $p$ (so $|G|=n=efr$). The widget draws the fixed-field tower
$\mathbb{Q}\subseteq K^D\subseteq K^I\subseteq K$ with step degrees $r$
(decomposition: $p$ splits into $r$), $f$ (residue / Frobenius), and $e$
(inertia / ramification), alongside the short exact sequence

$$1\to I(\mathfrak{P})\to D(\mathfrak{P})\to \operatorname{Gal}(\mathbb{F}_{p^f}/\mathbb{F}_p)\to 1$$

with $|D|=ef=|G|/r$ (orbit–stabiliser), $|I|=e$, and $D/I\cong\mathbb{Z}/f$ where
Frobenius lives. At an unramified prime $e=1$, so $I$ is trivial and $D$ is
cyclic of order $f$ generated by Frobenius. Changing the prime above $p$
conjugates $D$ and Frobenius, so only the conjugacy class $\operatorname{Frob}_p$
is canonical. Presets: completely split, inert, ramified.

## Params

See [`schema.json`](./schema.json) for the authoritative shape.

| field | type | purpose |
|---|---|---|
| `widgetId` | string | DOM id for the outer `<div class="widget">` wrapper. |
| `title`    | string | Display title (prose — `.ttl` is uppercased). |
| `hint`     | string (optional) | Short hint rendered next to the title. |

## Usage

```json
{ "type": "widget", "slug": "fr-decomposition", "params": { "widgetId": "w-fr-decomp", "title": "Decomposition and inertia groups" } },
{ "type": "widget-script", "ref": "w-fr-decomp" }
```

Then `node scripts/rebuild.mjs --only widget-params` to AJV-validate, and
`node scripts/rebuild.mjs` for the full byte-identical round-trip gate.
