Coding theory & error-correcting codes

Add redundancy on purpose: bits flipped by noise can be detected and undone, provided we know which patterns are codewords. From Hamming's $[7,4,3]$ to LDPC near the Shannon limit, codes turn algebra over $\mathbb{F}_q$ and sparse linear algebra over $\mathbb{F}_2$ into devices for surviving channel noise.

1. Hamming distance and the Singleton bound

A block code of length $n$ over an alphabet $\Sigma$ of size $q$ is a subset $C\subseteq \Sigma^n$. The three numbers that summarise it are the length $n$, the size $|C|=q^k$ (so the code has $k$ information symbols), and the minimum distance $$d \;=\; \min_{c\neq c'\in C}\, d_H(c,c'),\qquad d_H(x,y)=\#\{i:x_i\neq y_i\}.$$ We summarise the parameters as $[n,k,d]_q$. A code of distance $d$ can detect any pattern of $\le d-1$ errors and correct any pattern of $\le \lfloor (d-1)/2 \rfloor$ errors: closed Hamming balls of that radius around distinct codewords are disjoint.

The Singleton bound is the elementary observation that puncturing $d-1$ coordinates of $C$ must still leave distinct codewords distinguishable, so $$d \;\le\; n - k + 1.$$ Codes meeting this bound with equality are maximum distance separable (MDS). Reed–Solomon codes are the headline example.

Tradeoff in three numbers. Coding theory is the study of the achievable region in $(n,k,d)$-space. Singleton is one ceiling; the Plotkin, Hamming, Griesmer, and Linear-Programming (LP) bounds carve away more. Constructive codes try to hug these bounds.

2. Linear codes: generator, parity-check, syndrome

A code $C\subseteq \mathbb{F}_q^n$ is linear if it is a $k$-dimensional subspace. Two matrices describe it:

  • A generator matrix $G\in\mathbb{F}_q^{k\times n}$ whose rows span $C$. Encoding a message $m\in\mathbb{F}_q^k$ is the matrix product $c = mG$.
  • A parity-check matrix $H\in\mathbb{F}_q^{(n-k)\times n}$ whose kernel is $C$: a word $y\in\mathbb{F}_q^n$ is a codeword iff $Hy^\top = 0$.

If $G=[I_k\mid A]$ is in standard form then $H=[-A^\top\mid I_{n-k}]$ works. The minimum distance equals the minimum weight $\min_{c\neq 0}w(c)$ (linearity collapses pairs to differences), and that minimum equals the smallest number of columns of $H$ that are linearly dependent.

Given a received word $y=c+e$ with $c\in C$ and error vector $e$, the syndrome is $s = Hy^\top = He^\top$ — it depends only on the error pattern, not on which codeword was sent. Syndrome decoding precomputes a table mapping each syndrome to the minimum-weight error producing it; on receiving $y$ we compute $s$, look up $e$, and output $\hat c = y - e$.

The dual code $C^\perp = \{x:\langle x,c\rangle=0\text{ for all }c\in C\}$ is the $(n-k)$-dimensional code whose generator is $H$ and whose parity-check is $G$. Duality swaps $G$ and $H$ — and swaps "long messages, few constraints" for "short messages, many constraints." A code can even be self-dual: the famous extended binary Golay code $[24,12,8]$ and the binary Reed–Muller code $\mathrm{RM}(1,m)$ at the right parameters are examples.

3. Hamming codes

The simplest non-trivial family of perfect single-error-correcting codes:

  • Pick $m\ge 2$. Let $H$ be the $m\times (2^m-1)$ matrix whose columns are all non-zero vectors of $\mathbb{F}_2^m$, in any order.
  • Its kernel is the binary Hamming code $\mathrm{Ham}(m)$ with parameters $[n,k,d] = [2^m-1,\, 2^m-1-m,\, 3]$.

Distance $d=3$ because any two columns of $H$ are linearly independent (they're distinct non-zero vectors) but three columns can sum to zero. So Hamming codes correct exactly one error. The classic case $m=3$ is the $[7,4,3]$ code with $2^4=16$ codewords.

Perfect: The Hamming bound $|C|\cdot V_2(n,1) \le 2^n$ becomes $2^k\cdot(1+n) \le 2^n$, i.e. $k\le n-\log_2(n+1)$ — and Hamming codes meet it with equality. Every binary word is within distance $1$ of exactly one codeword; the closed balls of radius $1$ tile $\mathbb{F}_2^n$.

The decoding trick that made Hamming codes famous in 1950: arrange the columns of $H$ to be the binary representations of $1,2,\dots,n$. Then the syndrome $Hy^\top$ is the binary representation of the index of the flipped bit. No table lookup; the syndrome points at the error.

4. Reed–Solomon codes

Fix a finite field $\mathbb{F}_q$ with $n\le q$ distinct evaluation points $\alpha_1,\dots,\alpha_n\in\mathbb{F}_q$. The Reed–Solomon code with dimension $k$ is the image of the evaluation map $$\mathrm{ev}:\mathbb{F}_q[x]_{MDS: they meet the Singleton bound with equality.

This is the code in QR codes, on a CD's red book, in DSL modems, in RAID-6, and famously on the Voyager probes (after they were upgraded to a $[255,223,33]$ Reed–Solomon outer code in 1986). Decoders such as Berlekamp–Massey, Berlekamp–Welch, and Guruswami–Sudan all exploit the polynomial structure: a received word $r = c + e$ is the values $f(\alpha_i)+e_i$, and the polynomial $f$ can be recovered as long as the error vector is sparse enough that no other degree-$<k$ polynomial fits.

Why MDS matters: any $k$ of the $n$ symbols suffice to reconstruct the message. Erase any $n-k$ coordinates (a so-called erasure channel) and Lagrange interpolation through the surviving samples returns $f$. That's also why Reed–Solomon is the standard for distributed-storage erasure coding.

Generalisation. Replacing the line by an algebraic curve $X/\mathbb{F}_q$ of genus $g$ and the polynomial filter by sections of a divisor $D$ gives algebraic-geometric (Goppa) codes: $[n,k,d]_q$ with $k\ge \deg D - g + 1$ and $d\ge n-\deg D$. For curves with many $\mathbb{F}_q$-points (e.g. Hermitian, Suzuki, Drinfeld modular), AG codes beat the Gilbert–Varshamov bound for $q$ a prime-power square with $q\ge 49$ (i.e. $\sqrt q\ge 7$, so $q\in\{49,64,81,121,\dots\}$) — the Tsfasman–Vlăduţ–Zink theorem.

5. BCH codes — cyclic codes by design

A linear code $C\subseteq \mathbb{F}_q^n$ is cyclic if a cyclic shift $(c_0,c_1,\dots,c_{n-1})\mapsto (c_{n-1},c_0,\dots,c_{n-2})$ preserves $C$. Encode words as polynomials $c(x)=\sum c_i x^i \in \mathbb{F}_q[x]/(x^n-1)$; cyclic codes are exactly the ideals of that quotient ring, each generated by a divisor $g(x)$ of $x^n-1$. The polynomial $g(x)$ is the generator polynomial; its degree is $n-k$.

Bose–Chaudhuri–Hocquenghem (BCH) construction. Pick a primitive $n$-th root of unity $\beta\in \mathbb{F}_{q^m}$ (so $n\mid q^m-1$). For a target distance $\delta$, let $$g(x) = \mathrm{lcm}\big(m_{\beta^{1}}(x),\, m_{\beta^{2}}(x),\,\dots,\,m_{\beta^{\delta-1}}(x)\big),$$ the least common multiple of the minimal polynomials of $\delta-1$ consecutive powers of $\beta$. The BCH bound guarantees the resulting cyclic code has minimum distance $d\ge \delta$. Reed–Solomon codes are the special case $q^m=q$ (no extension), with $g(x)=\prod_{i=1}^{\delta-1}(x-\beta^i)$.

Why this is non-trivial: the consecutive-roots window forces any non-zero codeword $c(x)$ to have $\ge \delta-1$ consecutive roots, which by a Vandermonde determinant argument forces $c(x)$ to have $\ge \delta$ non-zero coefficients (weight $\ge \delta$). The minimal polynomials $m_{\beta^i}(x)\in\mathbb{F}_q[x]$ lump together cyclotomic cosets: powers of $\beta$ related by $i\sim qi\pmod n$. Pick a window of $\delta-1$ consecutive powers; the actual $g(x)$ may carry extra roots dragged in by cosets, often giving the true distance $d>\delta$ (Reed–Muller and Berlekamp–Massey refinements live here).

6. LDPC codes & iterative decoding

Low-density parity-check (LDPC) codes, invented by Robert Gallager in 1962 and rediscovered 1996, take the opposite design philosophy from BCH. Instead of an algebraic structure that gives a closed-form decoder, an LDPC code is defined by a random sparse parity-check matrix $H\in\mathbb{F}_2^{(n-k)\times n}$ — each row has only a handful of $1$s, each column the same. Decoding is iterative message-passing on the Tanner graph: a bipartite graph with $n$ variable nodes (codeword bits) on one side and $n-k$ check nodes (parity equations) on the other; an edge connects variable $i$ to check $j$ iff $H_{ji}=1$.

Belief propagation (sum-product). Each variable node carries a log-likelihood ratio $L(y_i) = \log\Pr(y_i\mid c_i=0)/\Pr(y_i\mid c_i=1)$. In each round:

  1. Each variable sends each neighbouring check the sum of its own channel LLR and every other check's outgoing message (excluding the destination).
  2. Each check sends each neighbouring variable a function combining incoming messages from its other variables: $L_{c\to v} = 2\,\mathrm{atanh}\!\Big(\prod_{v'\ne v}\tanh(L_{v'\to c}/2)\Big)$ — the soft analogue of XOR.
  3. After a fixed number of rounds (or until parity checks are satisfied), decode each bit by the sign of its posterior LLR.

On a tree the algorithm is exact; on the Tanner graph it's a heuristic that nevertheless gets within $\sim 0.0045\,\mathrm{dB}$ of Shannon capacity for well-designed irregular LDPC ensembles. The density evolution calculus rigorously tracks the recursion and produces designable codes.

Modern standards built on LDPC: DVB-S2 (satellite TV, 2003), WiFi 802.11n/ac/ax, 5G NR data channels (3GPP 2018; alongside polar codes for control). The performance gap to Shannon capacity is now small enough that the dominant engineering work is iterations-per-bit, not algebraic-distance-tuning.

Random vs. algebraic. Coding theory has a recurring split: algebraic codes (Hamming, BCH, Reed–Solomon) give closed-form decoders and provable distance, but plateau well below capacity. Random / pseudorandom codes (LDPC, polar, fountain) approach capacity but need iterative decoders and tail-bound analysis. Both species are now industrial; pick by gesture, not by aesthetics.

7. Lattice codes & sphere packings

For continuous channels (think Gaussian noise on a real-valued signal) the relevant object is a lattice $\Lambda\subset \mathbb{R}^n$: a discrete additive subgroup $\Lambda = \mathbb{Z}b_1 + \cdots + \mathbb{Z}b_n$ where $\{b_i\}$ is an $\mathbb{R}$-basis. Codewords are lattice points; the "minimum distance" is the lattice's shortest non-zero vector, $\lambda_1(\Lambda) = \min_{0\neq v\in\Lambda}\|v\|$. Spheres of radius $\lambda_1/2$ around lattice points are disjoint; the center density $$\delta(\Lambda) = \frac{(\lambda_1/2)^n}{\det\Lambda}$$ measures how tightly they pack.

Two endpoints define the field:

  • In dimension $8$, the $E_8$ root lattice achieves $\delta = 1/16$ and is optimal — Maryna Viazovska's 2016 proof. Each lattice point has $240$ nearest neighbours (the kissing number).
  • In dimension $24$, the Leech lattice $\Lambda_{24}$ is optimal (Cohn–Kumar–Miller–Radchenko–Viazovska, 2017) with kissing number $196{,}560$. Each point sees the other $196{,}560$ at exactly the minimum distance — an absurdly rigid configuration. The Leech lattice's symmetry group, modulo $\{\pm 1\}$, is Conway's sporadic simple group $\mathrm{Co}_1$.

Why this lives inside coding theory: a lattice $\Lambda\subset\mathbb{R}^n$ projected modulo a sublattice $\Lambda'\subset\Lambda$ yields a finite code (the quotient $\Lambda/\Lambda'$ inherits a distance), and many high-rate lattices arise by Construction A: lift a binary linear code $C\subseteq \mathbb{F}_2^n$ to $\Lambda_C = \{x\in\mathbb{Z}^n: x\bmod 2\in C\}$. Single-parity-check codes $[n,n-1,2]$ give the $D_n$ lattices; the extended Hamming $[8,4,4]$ gives $E_8$; the binary Golay $[24,12,8]$ gives a scaled Leech lattice (after a final $\mathbb{Z}/2$ twist). Channel codes and sphere packings are dual faces of the same problem.

Connections

Coding theory sits at the intersection of finite-field algebra, sparse linear algebra, probabilistic combinatorics, and discrete geometry. The open frontiers are quantum LDPC codes (low-overhead error correction for fault-tolerant quantum computers — Panteleev–Kalachev recently broke through the $\sqrt n$ distance barrier), the post-quantum cryptosystems built on hardness of decoding random linear codes (McEliece is back in NIST's standardisation), and the still-uncomputed precise capacity of the deletion channel.

  • Information theory — channel capacity — Shannon's noisy-channel theorem sets the absolute ceiling that LDPC and polar codes approach.
  • Abstract algebra — finite fields — Reed–Solomon and BCH live entirely in $\mathbb{F}_q[x]$; without finite-field arithmetic there is no encoder.
  • Additive number theory — sums of squares — counting lattice points inside a ball is the geometry-of-numbers question that bounds packing density.
  • Cryptography — lattice-based crypto — the same lattices that make great codes make hard-to-decode problems for post-quantum cryptography.
  • Spectral graph theory — expanders — good LDPC codes have Tanner graphs that are good expanders; Sipser–Spielman expander codes use this directly.
